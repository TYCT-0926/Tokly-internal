# 执行计划：阶段划分与逐阶段派发

回答一个问题：**按什么顺序做什么，当前该派什么**。里程碑验收细节的权威在[路线图](路线图.md)；本文只维护阶段总览与**当前阶段**的派发 Prompt（历史阶段的 Prompt 在本文件的 git 历史与 `reports/` 里，不留正文）。

## 工作模式（固定流程）

1. 一次只开一个阶段。本文只放**当前阶段**的完整 Prompt；
2. Prompt 交给执行 AI（全新上下文，能访问 `E:\Axiom\Tokly` 含只读 `internal/`）→ 执行者只推 `feat/*` 分支、写报告到 `internal/docs/reports/`；
3. 复审 Prompt 交给另一个 AI（**惯例分工：执行 = Claude，复审 = Codex**；高危阶段对抗式）→ 结论"通过/通过附建议"即关闭；"不通过"发回实现者，修完只复审修复点。**复审小修通则（2026-08-03 起）**：拼写、注释、文档同步、显而易见且立即可验证的小缺陷，复审者**直接在被审分支上修复并提交**，在报告「复审修复」节逐条记录（改了什么、为何属小、验证命令）；**大问题才判不通过**——凡触及裁决规则、schema 语义、事务边界、红线、或修复方式存在设计取舍的，一律反馈不代改；
4. 维护会话裁决遗留项、squash 合入、写关闭记录 → **回本会话领下一阶段 Prompt**（吸收本阶段报告后生成，不预写）。

## 并行规则

- **判据**：两个任务不碰同一批代码/文档、且后者不依赖前者的正确性 → 可并行；不同轨道（后端 / 设计基座 / 纯核验）之间的并行是白赚。
- **禁令**：**四不先于二的复审通过**（四扩建二的收敛契约代码，fold 被攻破则两边重做）；**八不先于三B**（R10：新 adapter 不先于 fixtures）；同一执行者工作区内，维护者操作前先 `git branch --show-current`（2026-08-03 实发事故：维护提交落到执行者分支，已修复——共享工作区的教训）。
- **当前可并行**：阶段二（执行中）∥ 阶段五（独立轨道，本文已含 Prompt）∥ 三B 待二的 spec 对齐产物（已落盘）后可开。三A 已完成。

Tokly 的多主题视觉由三层令牌系统驱动：用户只给种子（强调色/底色温/灰阶倾向），
引擎在 OKLCH 空间程序化派生全部语义色，经 gamut 映射与对比度质量门保证任何种子
都产出可读、感知均匀的结果。引擎唯一实现在 Rust（构建期与用户主题安装期共用，
内部 ADR-0017）。本任务是设计基座里程碑的全部：引擎 + 三份产物 + golden 快照。

## 任务 B：crates/tokly-tokens（纯函数 crate，无 IO 依赖注入路径除外）
新 crate：edition 2024、[lints] workspace = true、license = "MIT"。
色彩运算可用 palette crate（deny 白名单扩充按携带事项规则）。
1. ThemeFamily/VariantSeed 解析与校验（令牌系统 Tier 1 schema：仅结构/类型/
   可解析性/值域四项，无中间值域检查）。
2. OKLCH 派生引擎：背景阶梯、前景阶梯（grayTint null → C=0）、强调色系列、
   chart.series、heat[0..4]（dark/light 双模式 L 表 + C 分档）、状态色、
   border/state/shadow——按 manifest 全量，公式逐条对应令牌系统.md。
3. gamut 映射：保持 L/H、二分降 C 至 linear-sRGB 合法（容差 1e-6，上限 64 次）；
   heat ramp 另做整 ramp 统一缩放（min 比例，不逐点 clamp；C=0 跳过）。
4. 对比度救济：按令牌系统的完整算法（P(L) 谓词、0.005 粗扫取最近、二分精化
   1e-4、无解拒绝并报字段路径、|ΔL|>0.05 构建警告入日志）。
5. 质量门：对 8-bit 量化值算 WCAG 对比度，逐项断言令牌系统「质量门」表
   （fg.primary 7:1、fg.secondary 4.5:1、accent 3:1、onAccent 4.5:1、
   heat C 单调、相邻档 8-bit roundtrip OKLab 距离 ≥ 0.02、gamut 合法）。
6. ANSI 降级：OKLab 欧氏距离最近匹配、同距取最低 index、ANSI16 固定语义表；
   16 色域高明度低彩度 accent 落灰是已知损失，测试断言语义色不受影响。
7. linear() 弹簧采样：按动效规格参数采样至静止（位移与速度 < 1e-3），输出
   CSS linear() 停靠点串与总时长，作为令牌之一进产物。
8. 三份产物生成器：CSS 变量（[data-theme="<id>-<mode>"] 块）、Rust 常量
   codegen、TUI 主题 JSON（hex + ansi256 + ansi16）。输出目录 target/tokens/
   （不入库）。
9. cargo xtask tokens 子命令：调引擎生成三产物（xtask 保持零第三方依赖，
   经 cargo run -p 方式调用引擎二进制或库）。

## 设计身份简报（任务 C/E 的审美基准——specimen 的自由度在呈现，不在数值）
产品气质是**精密仪器**，不是 SaaS 营销页：数字是主角（一切读数 Maple Mono +
tabular-nums，右对齐）；一个强调色 + 全中性灰阶，成本上升不用红色告警；分隔靠
发丝线不靠卡片套卡片；暗部有温度（amber 的"示波器与琥珀屏"：暖近黑上数据像
仪表读数一样清晰，琥珀只出现在按钮/焦点/激活系列/热力图，数字永远中性色）。
质感对标一流设计系统的公开 tokens 文档页。绝对禁止（AI 味清单）：紫蓝渐变、
玻璃拟态、发光体、bento 卡片阵、>12px 圆角、重阴影、emoji、营销文案。

## 任务 C：DTCG 令牌源、真实字体与 specimen 页（packages/design-tokens，不含算法）
1. DTCG JSON：静态令牌（字号/间距/圆角/时长/字体栈）+ 五套 ThemeFamily 种子
   （主题.md 原样录入；sakura 无 bgImage）。
2. **真实字体**（排版是视觉身份的一半，用系统回退字体验收主题等于验收另一个
   产品）：Geist Sans 与 Maple Mono 的 woff2（仅所需字重，Regular/Medium/
   SemiBold + Mono Regular）入 packages/design-tokens/preview/fonts/，
   **OFL 许可证文本随文件入库**，来源与版本写进报告；@font-face 定义进
   preview 的 CSS（产品级字体管线属阶段七，此处只服务 specimen）。
3. **specimen 页**（纯静态 HTML + 生成的 CSS + 主题切换所需的最小原生 JS，
   无框架无构建）——按设计系统 brand-book 的标准做，结构固定为七节：
   a. 页头：产品名 + 主题切换器（5 主题 × 深浅，data-theme 交叉淡化 150ms；
      切换器本身照组件规格 §7 分段控件样式施工）；
   b. 色彩系统：每个语义令牌一行——色块 / 名称 / hex / 用途注释（取自
      令牌系统 manifest 用途列）/ **实测对比度值直接印在页上**
      （如 fg.primary on canvas = 12.4:1 ✓）；
   c. 排版样张：字号阶梯全展示；中西混排段落；tabular-nums 对齐演示
      （两列右对齐数字，等宽 vs 非等宽对比）；Maple Mono 读数样张
      （$12.80 / 3.4M / 2026-07-14 14:32）；
   d. 组件组合样张（**真实感数据，禁 lorem ipsum 与占位灰块**）：KPI 行
      （无卡片 + 发丝竖线，照组件规格 §3）、配额油表三种 provenance 形态
      （§2：official 实心 / local-estimate 描边斜纹不出百分比 /
      user-configured 虚线描边）、53×7 热力图（确定性 seed 的右偏 demo
      数据走非零日分位数分档——顺带验证分档函数观感）、5 行下钻表格
      （数字右对齐 + mini bar，§6）、状态色三枚（圆点 + 图标双通道）；
   e. 间距与圆角标尺：4px 网格可视化、圆角三档；
   f. 动效令牌：三档时长演示块 + spring linear() 缓动的 hover 演示
      （纯 CSS transform，与 ease-out 并排对比）；
   g. 每节配一句"使用规则"小注（从 manifest / 组件规格摘录）——specimen
      同时是内部设计参考文档。
