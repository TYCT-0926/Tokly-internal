原则：先把数据地基打穿，再做界面；每里程碑结束都是可 dogfood 的状态。（2026-08-02 按审查 §三 P2-14/15/16 重排：M1 加 `tokly report` 使里程碑可 dogfood；design-tokens 单列 M1.5；Dashboard 提前到 M2 且双源防 UI 过拟合；配额窗口入 M2。二轮审查后增设 M0.5 冻结门。）

## M0.5 · 冻结门（M1 动工前提，二轮审查总判决）

二轮外部深度审查总判决：**三个 P0 修复并冻结前，不得启动 M1 核心实现**——当前最多做 monorepo/CI 等可逆脚手架，不冻结数据库、不实现正式 adapter（[审查-2026-08-02-二轮](research/审查-2026-08-02-二轮.md) §4）。冻结三件：

- [ ] **收敛契约定稿**（[ADR-0002](adr/0002-数据架构.md)：事件身份 / 可比 revision 域 / 显式冲突 / 观测-投影两层模型 / 事务边界），以交换/乱序/重放/重建 property tests 验收
- [ ] **可执行 DDL 冻结**（[数据库-schema](数据库-schema.md)：全表 + 迁移 + 索引 + FK/CHECK + watermark 游标 schema + quota provenance + pricing history）
- [ ] **六源映射 golden fixtures**（逐字段映射快照；含 Codex legacy/paginated 双格式、OpenCode 两代 schema、Copilot 格式版本表、Claude cache_creation 裁决用例）

三件全部冻结并通过评审，才准动工 M1。

## M1 · 核心数据层（第一优先级）

目标：一条命令 `tokly scan`，把 Claude Code 的全部历史导入本地仓库；`tokly report` 出终端汇总表——里程碑可 dogfood 才成立。

- [ ] `packages/core`：SQLite schema 全表落地（以 [数据库-schema](数据库-schema.md) 为规范：source_instances / usage_events / conflict_observations / sessions / session_model_stats / tool_calls / event_charges / pending_messages / ingest_errors / watermarks / quota_snapshots / pricing_history）
- [ ] 增量摄取引擎：三类源水位线（JSONL / SQLite 活库 / API staging）+ 收敛契约 upsert（事件身份 + 可比 revision 域 + 显式冲突 + 同事务边界，见 ADR-0002）
- [ ] Claude Code adapter（首个，数据最丰富）
- [ ] 去重与收敛：`(sourceInstanceId, eventKey)` 主键；message-id + request-id 复合键防分支重复；**同 stream 取最后源记录**，跨流冲突进 `conflict_observations`（禁止取 max，二轮审查 §3）
- [ ] `packages/pricing`：LiteLLM 定价 JSON + 本地缓存 + 用户覆盖 + 模糊匹配；按事件时点匹配 `pricing_history` 生效区间计价
- [ ] `tokly report`：终端汇总表（今日/本周/总成本与 token；只聚合 `status='counted'`，native/computed 双列分别展示）——第一个可 dogfood 的使用面
- [ ] golden fixtures + 收敛性 property tests：六源真实样本（脱敏）逐字段映射快照；交换/乱序/重放/重建四场景终态一致（docs/开发流程.md）

## M2 · Web Dashboard v1（主战场）+ 配额窗口初版

- [ ] OpenCode adapter（直读 SQLite，原生成本）——Dashboard 以 Claude + OpenCode **双源**开发，防 UI 过拟合单源
- [ ] 概览：KPI（今日/本周/总成本与 token）、趋势图（uPlot）、GitHub 式热力图
- [ ] 钻取：按源 / 模型 / 项目 / 会话四级下钻
- [ ] 本地 HTTP 服务：Bun 内嵌服务器托管构建产物 + JSON API（仅 127.0.0.1 + 随机 token 鉴权，见 `docs/架构总览.md` 进程模型）
- [ ] 配额窗口初版：Claude 5h 窗口本地重建的 activity（observedUsage + unit）+ 燃烧率油表（标注推算、不出百分比，见 [ADR-0008](adr/0008-配额窗口.md)）
- [ ] 数据分层保留落地：raw 事件 90 天 → 日聚合永久（见 ADR-0002 分层保留节）
- [ ] 设计系统落地（`docs/设计原则.md` + `docs/design/`）

## M3 · 数据广度 + 配额完整化

- [ ] Codex adapter（rollout JSONL，legacy+paginated 双格式；`token_count` 累计值差分 + cache read/write 双减净输入公式；`rate_limits` 独立采集 → quota_snapshots）
- [ ] Gemini CLI adapter（chats 文件，含 `$set.messages` 全量检查点；用户已自开 OTEL 时被动利用 + 权威通道裁决）
- [ ] 配额窗口完整化：**范围明确只指 Claude + Codex 两源**（Claude 本地重建规则完善 + Codex 官方 rate_limits 快照；其余源有能力即补，不作承诺——二轮审查 §2）；窗口规则可配置（ADR-0008）
- [ ] `tokly statusline`：嵌入 Claude Code 状态栏的用量行（用户自行配置接入，不违反只读铁律；最强自传播面）
- [ ] `tokly serve --demo`：假数据模式（增长三件套之一，降低围观门槛）
- [ ] 能力矩阵：每个 adapter 声明字段能力，UI 按能力降级渲染

## M4 · TUI

- [ ] OpenTUI（**@opentui/solid** 路径，opencode 生产实证）：实时监控视图 + 历史浏览
- [ ] **Windows/Bun 组合实测验证前置**（风险登记 R1：issue #152 已关闭但留未完成项，实测前不定级）；降级预案：降帧 / 禁特效，仍不达标则引导走 Web——诚实标注，不承诺完美（ADR-0001）
- [ ] 主题机制：JSON 主题 + system 自适应（借鉴 opencode）

## M5 · 桌面端

- [ ] Tauri 2：系统托盘实时用量、可钉 Widget、完整窗口（复用 Web 构建产物）
- [ ] v1 内嵌 Bun sidecar；托盘/Widget Rust 直读 SQLite 为候选方向——**M5 开工时为最终决策门**（见 ADR-0004）
- [ ] 桌面通知：配额窗口将尽、异常消耗 spike（油表的价值一半在"快没油时响一声"；阈值规则可配置）

## M6 · 补盲与洞察

- [ ] Copilot：官方 API（用户授权 PAT，premium-request 粒度，标注口径差异；staging 整周期事务发布）
- [ ] Cursor：state.vscdb 只读解析（backup API 副本 + DB generation），v3 行 token 缺失时按 role 分离字符池估算并标注 `tokenQuality='estimated'`
- [ ] adapter 广度：Cline / Roo / Kilo 家族（一套 globalStorage 解析覆盖约 900 万安装）；Qwen Code（复用 Gemini adapter ~80%）
- [ ] adapter 贡献套件：spec 模板 + golden fixtures 脚手架 + 能力声明 checklist（社区扩源的包装）
- [ ] 智能洞察：异常消耗提醒、缓存命中率分析、模型成本对比建议
- [ ] **MCP Server**：本地 MCP 接口，让 AI 工具自查用量（"问 Claude：我这个月花了多少"——完全本地，闭环）
- [ ] **Tokly Wrapped**：年度回顾（年度 token、最爱模型、最烧钱的一天；热力图为视觉主角，可导出分享卡片）

## 明确不做（当前阶段）

- 本地代理拦截（违反只读铁律）
- 替用户开启 OTEL / 修改任何配置
- 云同步、账号体系、排行榜（与本地优先冲突，远期再议）
- 数据库加密（本地单用户工具，威胁模型不成立；见 SECURITY.md）
- 多设备同步（M6 后评估，aitrack 式 git-repo 同步为候选思路）

## 性能 SLO（验收硬指标）

| 指标 | 目标 |
|---|---|
| CLI 启动 | < 100ms |
| 增量扫描 | < 1s（水位线命中）；首次全量 < 30s（万级文件） |
| daemon 常驻内存 | < 50MB |
| Dashboard 任意聚合查询 | < 100ms |
| Dashboard 首屏 | < 300ms（本地数据） |
| 数据库体积（分层保留后） | 每年重度使用 < 100MB |
