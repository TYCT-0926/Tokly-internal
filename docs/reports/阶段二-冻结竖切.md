## 三项实测（2026-08-03，Windows 11，Intel64 Family 6 Model 154（12th 代 i7 移动端）；file DB + WAL，release 构建；两轮取稳）

1. **PRAGMA cache_size 默认 vs -16000**（10 万事件行聚合查询，12 次迭代）：default min 100.28ms / median 136ms；-16000 min 100.26ms / median 122ms。**两者统计上不可区分——bun:sqlite 栈的“4–5 倍提升”在 rusqlite/Windows 该负载上不成立**（数据集约 40MB，疑被 OS 文件缓存吞掉差异）。这正是 schema 文档 PRAGMA 注释要求重测的说法；数字已得，PRAGMA 值本身未动，是否降为默认由 M0.5 spike ① 连同 mmap/负载形状一并裁决。
2. **STRICT vs 非 STRICT 批量插入**（10 万行单事务）：261,231 vs 261,120 rows/s——**STRICT 零插入代价**，「全表 STRICT」决策无性能负债。
3. **tool_calls WITH vs WITHOUT ROWID**（30 万行插入 + 1 万次按事件查询）：插入 353k vs 567k rows/s（**WITHOUT ROWID 快约 1.6 倍**）；查询 12.5 vs 9.1 µs/次（快约 27%）。支持窄表转 WITHOUT ROWID；按 schema 文档约定留给 spike ① 定稿，本阶段 DDL 未动。

## 实现对规范文档的解释与偏差（按红线逐项记录，等裁决）

1. **裁决规则 1「跳过」的收敛化解释**：字面的「同流同代更大 position 同 hash → 跳过」若按增量实现，投影的 source_position 列会依到达顺序而异（先 10 后 20 停在 10；先 20 后 10 停在 20）——**不满足交换性**。实现取集合语义：投影坐标 = 流终态（最大 canonical position），内容不变。这是唯一能使四场景逐字节一致的读法；如维护者认为投影应保留首见坐标，需同步修改收敛验收口径。
2. **conflict_observations 的 existing/incoming 列语义**：列名暗示到达顺序，但顺序相关的写法会破坏快照一致性。实现取规范形态：existing = 裁决胜者坐标，incoming = 败者坐标，行集按 (kind, incoming 四元组) 排序整写——冲突表因此也是观测集合的纯函数。observed_at 取败者观测的 observed_at（数据而非时钟）。
3. **「(origin_stream, stream_generation) 字典序最小」**：stream_generation 是 INTEGER，实现按元组序（stream 字节序，generation 数值序）。若字面理解为两者都转字符串比较，generation ≥ 10 时结果不同。
4. **同坐标非终态位置的矛盾也留证**：规则 3 只写了终态坐标；实现对流内任意坐标的同位置异 hash 都记 conflict（源自相矛盾必须可见），投影不受非终态冲突影响。
5. **normalizer_version 与 UNIQUE（评审后已闭合）**：观测 UNIQUE 六元组不含 normalizer_version——初版 INSERT OR IGNORE 会静默丢弃升级后的重扫（评审 blocker，实验复现）。现实现：撞坐标时确定性裁决——更高 normalizer_version 胜出（就地替换 normalized 并重折叠，DDL 未动）；同版本不同 normalized 属 adapter 缺陷，取字典序较小者并记 `ingest_errors`（error_code `normalizer-divergence`）；observed_at 收敛到 min。IngestOutcome 增 `Superseded` 档。观测层"只追加"在此收窄为"坐标只追加，同坐标内容可被更高版本归一化替换"——这是使 ADR-0002 重归一化锚点真正可用的最小语义，请维护者追认。
6. **投影 observed_at / updated_at 的决定论定义**：observed_at = 该 key 全部观测的 min(observed_at)，updated_at = max(observed_at)——用观测数据而非挂钟，否则重放/乱序下不收敛。
7. **cache-split-mismatch 的 excluded 行 token 值**：spec 未定 excluded 行存什么；实现保留可解析值（5m=aggregate）+ rawUsage 原文留证，聚合不受影响（status 过滤）。

## 四轮修复（2026-08-03，依 ADR-0002「四轮定案」；主体为 P5/P6 全称性质）

1. **零触碰域精确化（必修 1）**：实现本就无条件推进水位线，修在 oracle 侧——stale 反例按定案改写为「游标照常推进 + 其余全域逐字节不变」（`snapshot_without_watermarks` 新比较视图）。
2. **留证谓词精确化（必修 2）**：adjudication 改四态返回（Untouched / TimeOnly / EvidenceOnly / ContentReplaced），fold 返回胜者签名与变化标志；`frozen-session-reactivated` 条件 = **胜者实际被改写 × 会话 frozen**——跨流败方、duplicate、低版本的负例已入回归。Untouched 严格对应 Duplicate 结局（同版本分歧败方虽不改观测但写证据，归 EvidenceOnly → Superseded，保证 Duplicate ⇒ 真零触碰）。
3. **P5（跳过零副作用）**：复用四场景生成器，整批两趟摄取；每次 Duplicate 结局断言 fold 态 + 证据表逐字节不变、游标按单调规则推进。第二趟前**清空水位线**——这正是定案点名的「降级 adapter 同位置打转」场景：游标落后于已知观测时，跳过仍必须推进。
4. **P6（证据正当性）**：生成器持真值的模型测试——操作序列含摄取（版本 × 同版本分歧变体 × 到达时间盐）、剪枝、冻结三类；模型按 ADR 条文直译裁决规则，终态对 conflict_observations（全逻辑列含 resolution）与两个生命周期错误码做**双向 multiset 比对**：无谓词的证据行、缺行的谓词、重复逻辑行同判失败。另加**永久生成器覆盖门禁**（384 样本断言分歧/陈旧跳过/重复/剪枝/冻结/再活跃/重观测/多坐标八类角落全部非零命中——防性质空转）。
5. **突变自证（定案要求，含两次自我纠偏）**：临时禁用四个历史修复，验证性质在标准 96-case 预算内自行抓出——A 抑制跳过时的游标推进 → P5 红；B 冲突对身份掺回 observed_at（三轮缺陷）→ P6 红；C 删再活跃留证（三轮缺陷）→ P6 红；D 删低版本零触碰（三轮缺陷）→ P6 红。**自证过程本身修正了两处 oracle 洞**：初版 P5 抓不住 A（生成器里 Duplicate 永远出现在游标已最大处）——加游标重置趟后闭合；B/D 在 24 cases 下漏、400 cases 抓到——判定为触发密度而非盲区，收紧 P6 坐标池（2 键 × 2 流 × 2 代 × 2 偏移）使 96 cases 稳定命中后复测通过。每次突变经 scratchpad 副本还原，最终 store.rs 与基线逐字节一致。
6. **范围外观察处置**：属测试库工件——突变运行失败落下的 `*.proptest-regressions` 种子文件，已清理并加 .gitignore（防误入库）；fixture 快照另行强制重生成，sha256 与提交版逐字节一致（2 条证据行，无重复冲突行）。
7. **操作事故记录（诚实留痕）**：突变还原初版误用 `git checkout` 将本轮未提交的 store.rs 重构一并还原到 HEAD——违反"破坏性操作前清点未提交工作"纪律；因本轮改动全部来自确定性补丁脚本得以完整重放恢复，后续突变改用 scratchpad 副本还原。最终态经完整验证链复核。

## 三轮修复（2026-08-03，针对 阶段二-复审.md「三轮复审」四项必须修复）

1. **冲突对身份去掉 observed_at**：补插判定只按逻辑坐标（kind + existing 四元组 + incoming 四元组 + resolution）；observed_at 是派生值，随当前集合**置值**（不取 min——跨版本替换会抬高观测时间，min 记忆会使增量停在旧值而重建取新值，两路分叉；置值语义下两路都收敛到集合当前派生值）。复审反例固化为 `replayed_conflict_pair_has_one_logical_row`（双顺序 + 重建三路 multiset 一致，时间收敛到 50）。
2. **normalizer 低版本零改动 + divergence 时间收敛**：低版本到达在函数首行短路返回 Duplicate，观测/投影/证据/时间零触碰（`stale_normalizer_version_is_a_zero_change_skip` 以全域快照前后比对固化）。时间语义精确化：观测行 observed_at = **胜者内容各次到达的 min**（替换时取胜者自己的时间，不并败者——并了会在另一顺序下不可复现）；divergence 行 observed_at = **该坐标全部同版本到达的 min 累积**——胜者的重复到达也折入证据行（复审攻破 B 的根因就是这条缺失）。`normalizer_divergence_time_converges_across_replay_order` 固化双顺序全域一致（胜者 alpha / 观测 50 / 证据 50）。
3. **重建清除孤立 fold 冲突行**：清除谓词由「键在非 pruned 投影中」改为「键**不在** pruned 投影中」——无投影可达的孤立 fold-kind 行（哨兵）一并清除，pruned 键的证据仍保留。六表哨兵测试 `sentinels_are_removed_from_every_fold_owned_table` 固化（6/6 归零 + 真实键照常重放）。
4. **frozen 再活跃留证**：此前把裁决读成"仅登记常量"是误读——ADR 修订 4 要求**记录可见项**，仅解冻语义留待后续；已在 ingest 路径落地（fold 实际执行且事件会话为 frozen 时记 `ingest_errors`，身份 = 会话键，UNIQUE 幂等合并）。选 ingest 路径而非 mark_session_dirty 内部：重建的重折叠不应重复累计到达证据，到达信号只在到达时记。`frozen_session_reactivation_is_visible` 固化（两次到达合并为一行 occurrence=2，聚合保持 777、投影照常收事件）。

## 二轮修复（2026-08-03，依 阶段二-裁决.md「第二轮裁决」与 ADR-0002「二轮修订」四条）

1. **冲突 = 观测集合的历史性质（修订 1）**：冲突派生改为集合纯函数的**全配对闭包**——规则 3 同坐标异 hash 全配对、规则 4 跨流异 hash 全配对（同流跨代仍不构成对）。该闭包对集合增长单调，故增量路径改为「只补插缺失行、永不删除」（NOT EXISTS 幂等插入），has_conflict 由闭包非空派生；重建从集合重派生同一批。选全配对而非终态/组终态粒度的论证：任一跨流异 hash 观测对在某个到达顺序下都曾是双方流的瞬时终态，而组终态随集合增长会移动、不单调——全配对是唯一同时满足「增量不删」与交换收敛的定义。**推论已在 fixture 上显形**：fork 逐字节复制终态时，被覆盖的草稿与复制行也构成历史冲突（msg_A 现 has_conflict=1）——某些顺序下二者确曾同为终态，按修订 1 这是要保留的事实；claude 实测 2.5 万异 payload 组意味着真实库的冲突行量级会上升，量级影响请维护者知悉。回归：`historical_conflict_remains_visible`（增量/交换/清空重建三路径终态一致）、`refold_after_pruning_must_preserve_historical_conflict_flag`（四入口覆盖 + 计数合并）、三 hash 同坐标改为全配对断言（3 行）。

4. **pruned/frozen 四入口（修订 4）**：`observations_pruned_at` 非空的投影在 ingest / normalizer 替换 / dirty 重算 / 全量重建四入口一律短路（fold_key 顶部集中守卫 + ingest 前置检查）；该键新观测照常只追加入观测层并记 `ingest_errors` `pruned-key-reobserved`（UNIQUE 计数合并，回归验证 occurrence=2）；frozen sessions 从 dirty 扫描与全量重建排除（mark_session_dirty 对 frozen 行抑制、重建的派生层清空/重算均带 `frozen_at IS NULL`），零 counted 删除仅限非 frozen。`FROZEN_SESSION_REACTIVATED` 仅登记为公开常量，语义留待 M1。回归：`refold_after_pruning_...`（入口 1/2/4）、`frozen_sessions_are_never_recomputed_or_deleted`（入口 3/4 + 复审的 777 覆写反例 + 支撑事件消失后永久汇总仍在）。
