## 实现口径（规格两可处的裁决）

规格无一处被偏离；以下为存在解释空间处的裁决（独立参照实现同口径后 **1,188 项数值全部一致**）：

1. chart.series 的"中性灰" = C=0 纯中性（fg 阶梯显式给 C=0.008，此处字面即纯中性）；
2. solid 衍生令牌（hover/muted/series.3/series.5）用 solid 过 gamut 后的最终 C；heat 的 C 基数用种子 accent 的 C（heat 有自己的整 ramp 缩放）——官方十变体两种读法数值相同；
3. heat 相邻档检查含 (heat.0, heat.1) 对，共 4 对；
4. onAccent 对比度完全平手取 #FFFFFF；救济粗扫等距平手取较低 L（官方种子均不触发）；
5. 8-bit 量化顺序：linear clamp [0,1] → sRGB 编码 → round(×255)；WCAG 亮度分段阈值取 2.x 原文 0.03928（对 8-bit 输入与 0.04045 无可区分差异）；
6. ANSI 匹配前 alpha 令牌按 CSS 口径（gamma 空间 8-bit）合成到 bg.canvas；bg.scrim 与 shadow.overlay 无终端形态，不进 TUI 产物；
7. **消色差归零 ε=1e-6**：转换矩阵在 r=g=b 输入上留 ~3e-8 残余彩度，会让 mono 的全部 "C=0" 分支失效；解析时 C<1e-6 归零（主题.md 自身断言 mono accent 实测 C=0）；
8. Tier 1 校验拒绝未知字段（笔误可见）；grayTint 为必填可空；id kebab-case 具体化为非空 + [a-z0-9-] + 首尾非连字符；
9. CSS 产物：alpha 令牌用 `rgb(R G B / A)` 现代语法；每主题块附 `color-scheme`（不改变任何令牌值）；radiusScale≠1 时块内覆盖圆角三档。

（原第 16 条"纯中性 gamut 合法性豁免"已被二轮裁决推翻并从实现移除，见「二轮修复」。）

## ANSI16 已知损失清单（16 色域固有，语义色不受影响）

固定语义映射（bg/fg/status/border/heat.0）按规格表钉死。无定性令牌最近匹配的值得注意落点：

- **中暗色漂向有彩暗锚点**：amber/paper/sakura-dark 的 heat.1（暗棕/暗粉）→ `red`(maroon)；amber/paper-dark heat.2 → `yellow`(olive)；slate-dark heat.1/2 → `blue`/`cyan`；各 dark 变体 bg.overlay → `blue`——OKLab 距离下中暗灰确实更近暗彩锚点（参照实现逐例手工验算同结论）。
- **高明度低彩度 accent 落灰/白**：amber/slate/paper/sakura-dark 与 mono-dark 的 accent.solid → `white`（规格预告的已知损失）；mono-light accent(#2A2A2A) → `red`、sakura-light accent → `brightRed`。
- 测试断言 status.success/warning/error 全变体固定 green/yellow/red。

结论：16 色降级只保语义与明暗结构，不保色相；256 色档无此问题。二轮裁决 ③ 已接受（braille 密度承载信息）。
