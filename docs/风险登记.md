## R2 · 价格的时间维度

- **风险**：用今天的价目表回算历史成本是 bug 温床——模型调价后，历史月份的成本会被错误改写；`tokly reprice` 的设计初衷（修正历史）反而变成污染源。
- **证据**：LiteLLM 价目持续滚动更新，无生效日期维度（2026-08-02 审查 §四 盲区 3）。
- **对冲**：价目表引入**生效日期**维度——`pricing_history` 表带 `[effectiveFrom, effectiveTo)` 区间，reprice 用 `event.timestamp` 匹配事件时点有效价格（[ADR-0002](adr/0002-数据架构.md) 成本所有权节，二轮修订落地）；远程表无历史时**自建覆盖层**（按抓取时间归档价目快照，`pricingVersion` 已逐事件记录，为重算提供锚点）。
- **状态**：方案已定（DDL 已冻结进 docs/数据库-schema.md），pricing 层实现时落地（M1–M3 内）。

## R3 · 多通道同源双计

- **风险**：同一源的多个采集通道并存（Copilot 的 OTEL / session-state / 个人 API / 企业报告是最完整实例），直接并库必然重复计数。
- **证据**：ccusage #1174（双源共存去重是开放问题）；2026-08-02 审查 §四 盲区 4。
- **对冲**：**用户配置唯一权威通道**；非权威通道照常入库但 `status='excluded'` + `channel` 列区分，默认不进聚合（[ADR-0002](adr/0002-数据架构.md)、公开仓 `docs/sources/copilot.md` 权威裁决条；Gemini 的 chats/被动 OTEL 双通道同模式）。
- **状态**：已对冲（契约层），待实现。

## R4 · 静默丢数据三点位（方案已定，待实现）

- **风险**：三个已识别的静默丢数据点——① Cursor 库 VACUUM 后 rowid 重编使水位线失效；② OpenCode `finish` 永空的中断轮次永远悬置不结算；③ `(time_updated, id)` 复合游标页边界同毫秒并发漏行。
- **证据**：2026-08-02 审查 §三 P1-7（各点位机制分析）；30 天删源的源上静默丢弃 = 永久丢弃（§四 盲区 6）。**二轮审查 §2 更正：旧"已修"状态错误**——① 旧「水位线 rowid→key 反查」被证伪（`UNIQUE ON CONFLICT REPLACE` 会把锚点 key 移到新 rowid 造成误报；全扫后低 rowid 被旧 revision 拒绝）；② 旧定稿规则未阻止水位线越过未定稿行（过滤后照样推进 = 永久丢数）；③ 2 秒回退仅缓解，不构成"修"。
- **对冲**：方案已定（二轮审查 §2，[ADR-0002](adr/0002-数据架构.md) 水位线节）——① **backup API 副本 + DB generation**（DB 头 change counter + schema cookie + 首 N 行采样哈希；rowid 只在同 generation 内作 position）；② **`pending_messages` 状态机**（每轮先按 ID 重读；finish 非空 / error 非空（已有 token 照常计数）/ 15 分钟陈旧 → 定稿；水位线不越过任何 pending id）；③ **轮内严格分页（单只读事务一致快照）与跨轮 checkpoint 回退分离** + 尾部 safety horizon + 周期全量 reconciliation。兜底可见性靠 `ingest_errors` 表。
- **状态**：**方案已定，待实现**（2026-08-02 二轮更正，非"已修"）；实现时三个点位各至少一个回归用例，并纳入收敛性 property tests（交换/乱序/重放/重建，公开仓 docs/开发流程.md）。

## R6 · Linux WebKitGTK 桌面体验（2026-08-02 三轮终审新增）

- **风险**：桌面端 Tauri 2 在 Linux 依赖系统 WebKitGTK：发行版间 WebKitGTK 版本碎片化，旧版本 CSS / 渲染能力与开发基线有差距；透明窗口在部分 NVIDIA 驱动下渲染异常（[ADR-0004](adr/0004-桌面端分发.md) 边角坑）。Linux 桌面可能成为三端体验最弱一环。
- **证据**：ADR-0004 边角坑登记（二轮审查 §三 P1-12 起）；WebKitGTK 版本随发行版锁定，应用侧不可控。
- **对冲**：① 最低依赖定 **webkit2gtk-4.1**，低于该版本安装期明示警告；② 透明窗口**默认不透明**，仅作显式开启项；③ Linux CI 截图冒烟（关键页面视觉回归进 CI，与动效规格验收门一致）；④ 保底路径诚实标注：Linux 桌面体验不达标时引导 Web Dashboard + TUI（两者不依赖 WebKitGTK）。
- **状态**：开放；M5 桌面里程碑内首次实测。

## R7 · macOS WebKit CSS 滞后（2026-08-02 三轮终审新增）

- **风险**：桌面窗口经系统 WebView 渲染（macOS WebKit / Linux WebKitGTK），CSS 新特性落地滞后于 Chromium 基线；Cascade Layers、OKLCH 等栈内特性在旧 WebKit 上可能缺支持或行为差异，造成桌面窗口与浏览器端视觉分叉。
- **证据**：Tauri 使用系统 WebView 而非捆绑 Chromium（这是体积优势的来源，[ADR-0001](adr/0001-技术栈与运行时.md) / [ADR-0004](adr/0004-桌面端分发.md)）；WebKit 特性节奏由 OS 版本决定，应用侧不可控。
- **对冲**：① 最低系统版本 **macOS 12+**，低于此不支持；② **Lightning CSS** 按目标浏览器基线自动降级 / 加前缀（构建期已锁定，ADR-0001）；③ 三平台（含 WebKit 系）视觉回归截图进 CI（动效规格验收门，不变）；④ OKLCH 派生全部构建期完成，运行期只消费 sRGB 字面量（[ADR-0005](adr/0005-主题架构.md) 三产物）——从根上消除运行期 OKLCH 支持依赖。
- **状态**：开放；M5 首次三平台截图比对时验证。
