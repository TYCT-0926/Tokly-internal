# 仓库策略：开源与闭源的边界

- 状态：accepted
- 日期：2026-08-02

## 决策：双仓库

| | `tokly`（公开） | `tokly-internal`（私有，本目录） |
|---|---|---|
| 内容 | 全部代码、公共文档子集 | 战略与设计内部文档 |
| 托管 | GitHub public | GitHub private（或仅本地） |
| 开发方式 | 标准开源：issue/PR 全公开 | 内部设计、审查、规划 |

**公开仓库收的（公共子集）**：`README.md`（英）· `LICENSE` · `SECURITY.md` · `CONTRIBUTING.md` · `docs/开发流程.md` · `docs/sources/`（数据源 spec——它们是 adapter 贡献者的 funnel，审查已定性为"全场最好的贡献通道"）· `docs/设计原则.md` · `docs/git-规范.md` · `docs/代码风格.md` · `docs/文档规范.md`

**私有仓库留的（内部子集）**：`docs/adr/`（战略决策，含竞品判断与商业取舍）· `docs/research/`（竞品调研、外部审查报告）· `docs/路线图.md`（发布节奏是战略）· `docs/风险登记.md` · `docs/架构总览.md` · `docs/design/`（设计图纸——公开仓库只沉淀最终 design-tokens 包的文档注释）· `docs/仓库策略.md`（本文）· 本策略相关讨论

理由：公开仓库需要的一切（构建、贡献、理解代码）必须自给自足；内部的竞品分析、审查记录、路线图是战略资产，不公开。sources spec 公开是深思熟虑的例外——它们是社区贡献 adapter 的说明书，公开收益远大于暴露。

## 同步规则

1. **单向流动**：公共子集以公开仓库为权威，私有侧不复制；内部子集**永不**进入公开仓库（包括 git 历史——公开仓库从 M1 第一个 commit 就是干净的）。
2. **物理位置（2026-08-02 改：嵌套双仓）**：工作根目录 `E:/Axiom/Tokly` 本身是**公开仓**（代码 + 公共文档）；其内 `internal/` 子目录是**私有仓** `tokly-internal`（独立 .git，外层 .gitignore 排除）。一个文件夹工作，按目录天然分流：根目录的改动进公开仓，`internal/` 里的改动进私有仓。CLAUDE.md/AGENTS.md 两处各有一份适配版。
3. **泄漏与误删防线（2026-08-03 重写：嵌套布局把风险提高了一个量级，"发布前检查"不够）**。嵌套结构有两条真实路径：一次 `git add -f`、误改 `.gitignore` 或 IDE 的"全部加入版本控制"会把内部文档送进公开仓；**`git clean -xdff` 会删除 ignored 目录，即整个 `internal/`**——而这正是清理 Rust `target/` 时最常敲的命令。五重对冲，缺一不可：
   - 外层 `.gitignore` 写 `/internal/`，**并**在 `.git/info/exclude` 重复一份（后者不随仓库分发，误改 `.gitignore` 时仍生效）；
   - **pre-commit hook 硬拒**任何路径含 `internal/` 的暂存文件；
   - CI 加同规则检查（防 hook 被 `--no-verify` 绕过）+ 私有文件名单 grep；
   - **禁用 `git clean -xdff`**，清理走 `cargo clean` 或 `git clean -xdf -e internal`；
   - 私有仓保持独立远端并及时推送——它是唯一不依赖本地磁盘的副本。
   发布前仍跑 `git log --all --full-history -- docs/adr docs/research` 类历史检查，但它现在是最后一道而不是唯一一道。
4. **内部文档引用公开代码**：行号引用会腐坏，引用公开代码用 `path:symbol` 而非 `path:line`。
5. **布局的备选与回退条件（2026-08-03 记录）**：并列布局（`Tokly/public` + `Tokly/internal`，父目录不是仓库）能从结构上消除上述全部路径，代价只是公开仓根目录不等于工作根目录。**当前采用嵌套 + 五重对冲；若任一对冲失效一次，即改并列**——这个触发条件写下来，是为了将来不用重新辩论一次。相关风险登记见 [风险登记](风险登记.md) R12。

## 不做

- 不做单仓库 + 发布时剥离 docs（git 历史仍含全部文档，等于没剥离）
- 不做私有开发、定期倾倒代码到公开（社区 PR 无法回流，开源变开源坟场）
