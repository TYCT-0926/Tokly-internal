# 反模板设计守则（施工强化条款）

> 2026-08-04 新增。设计原则的「禁止清单」说的是**不许有什么**；本守则说的是**必须做到什么**——前者防丑，后者求好。任何 UI 施工任务（阶段七A/七B/九/十）的 Prompt 必须引用本文，验收清单必须逐项过。

## 一、身份先于组件

施工前先回答一句话：**这一屏在模仿什么真实物件？** Tokly 的答案是**精密仪器**——示波器、万用表、飞行仪表盘：读数比装饰重要，刻度比色块重要，安静比热闹重要。每个设计决定都要能回答"这是不是让它更像一台仪器"。

不能回答的，就是模板在替你做决定。

## 二、八条 AI 味的具体症状（逐条自查，命中即改）

| # | 症状 | 为什么是 AI 味 | 正解 |
|---|---|---|---|
| 1 | **均匀圆角卡片阵**：所有块都是 `border-radius` 相同的白/灰卡片，网格等距排列 | 生成式默认布局。真实设计里层级是**不均匀**的：主角有边界，配角没有 | 主角用发丝线或留白界定，配角直接排在 canvas 上（组件规格 §3 的"无卡片 KPI"就是这个原则） |
| 2 | **每块都有标题 + 图标 + 副标题**的三件套 | 填充式思维——怕空，所以每格都塞满 | 标题只在**需要区分**时出现；图标只在**替代文字**时出现；副标题多数时候是废话 |
| 3 | **等分栅格**：12 列均分、三卡并排、每行等高 | 排版器默认值，不是排版决定 | 按**信息权重**分配空间：主读数占的宽度应该明显大于次要指标 |
| 4 | **色彩用来分类**（每个类别一个颜色） | 调色板当分类工具是最省事的做法 | 单强调色 + 中性灰阶；类别用**位置、排序、标签**区分，不用色相 |
| 5 | **动效均匀涂抹**：每个元素都有 hover 缩放、每次出现都淡入 | "加点动效显得高级" | 表现力预算一线一点（编排规格）；其余动效只做**状态反馈**，不做表演 |
| 6 | **数字被当文本排版**：非等宽、不对齐、无千分位或滥用千分位 | 忽略了数字是本产品的主角 | 一切读数 tabular-nums + Maple Mono + 右对齐；紧凑记数只在卡片与轴标签 |
| 7 | **空状态是插画 + 鼓励语** | SaaS 模板标配 | 一句具体指令 + 一个动作（组件规格 §11），无插画无 emoji 无营销腔 |
| 8 | **首屏是 hero**：大标题 + 副标题 + CTA | 落地页思维用在工具上 | 工具的首屏是**数据本身**；产品名只在导航角落 13px |

## 三、必须做到的"顶级"细节（可验收）

这些是区分"能用"和"讲究"的地方，逐项都要在报告中说明落地情况：

1. **光学对齐 ≠ 数学对齐**：图标、箭头、圆点与文字基线的视觉重心对齐（数学居中在小尺寸上会显得偏上）。
2. **数字列的小数点对齐**：`$12.80` 与 `$1,204.05` 右对齐时小数点必须成列。
3. **hover 不位移**：表格行、导航项 hover 只改底色，绝不改 padding/border 宽度导致 1px 抖动。
4. **焦点环不裁切**：`outline-offset` 留出空间，焦点环不被父容器 `overflow` 切掉。
5. **首屏无布局抖动**（CLS = 0）：骨架屏与真实内容**等形等高**，数据到达时零位移。
6. **发丝线真的是发丝**：1px 在 2x 屏上不应变成 2px 视觉；用 alpha 而非更浅的实色，保证深浅主题下都成立。
7. **长文本有明确策略**：项目路径、模型名过长时是截断（哪一端？）还是缩略中段？必须一致且可预测。
8. **空数据与零值可区分**：`0` 和"没有这个维度"必须视觉不同（本产品的溯源纪律，见组件规格 §11）。
9. **键盘操作有完整回路**：Tab 顺序符合视觉顺序、浮层关闭焦点回到触发元素、快捷键提示可见。
10. **两主题各自成立**：不是深色反色成浅色——浅色主题的对比、阴影、发丝线 alpha 都单独调过（令牌系统已保证色值，你要保证的是**用法**）。

## 四、创意的容许区间

规格锁死的是：色值、间距网格、字号阶梯、动效时长与曲线、组件的信息结构、表现力预算。

**创意空间在这些地方**（鼓励，且是评审加分项）：

- 信息的**编排与密度**——同样的组件，怎么排出更好的阅读节奏；
- 空间的**层级表达**——用留白、发丝线、对齐关系造层级，而不是加边框加底色；
- 微观交互的**手感**——hover/focus/active 的时机与幅度，让操作有确定感；
- 数据可视化的**表达力**——在图表纪律内（单色相、无渐变填充、无滚动数字）把趋势讲得更清楚；
- 状态与边界情况的**体面处理**——加载、空、错、降级、超窗，这些地方最见功力。
