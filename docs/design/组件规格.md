# 组件视觉规格（三端）

通用纪律见公开仓 `docs/设计原则.md`（禁止清单、动效、验收清单）。此处只写组件级规格。

> **2026-08-03 四轮修订**（依据 [审查-2026-08-03](../research/审查-2026-08-03.md)）：补四个缺失组件——**配额油表**（被论证为差异化第一位却没有任何规格）、**设置界面**（R3 权威通道的落地面）、**首次运行**（产品第一印象时刻）、**数据健康**（冲突与坏行的可见性只到数据库层）；修热力图标定窗口与分档函数；补超出保留窗口的下钻形态、i18n 布局适应、TUI 深度；并把散落的字面量收进末尾的 Tier 3 登记表。

## 0. 数值纪律（本文档的前提）

间距、字号、色值一律引用令牌。**组件级尺寸允许存在，但必须登记在文末的 Tier 3 尺寸表**——原文既写"禁止字面量"又用了几十个未登记数值，是设计系统内部最实质的一处不自洽。规则收敛为：

- **间距走 4px 网格**（4/8/12/16/24/32/48），无例外；
- **组件尺寸**（导航宽、行高、单元格边长等）走 Tier 3 登记表，施工时不得即兴新增；
- 新增任何组件数值：先改登记表，再施工。

## 1. 布局壳（Web / 桌面窗口）

- 左侧导航 `nav.width`，`bg.canvas`，右缘 `border.hairline`；无 logo 块，顶部仅产品名（`nav.brand` 字号，fg.secondary）
- 导航项：`nav.item` 字号 fg.secondary；激活 = `state.active.bg` + 左缘 2px accent.solid；hover = bg.raised
- 内容区最大宽度 `content.max`，左右 padding 32px，垂直节奏 24px
- 顶栏右侧：时间范围分段控件 · 主题切换 · **数据源状态点**

**数据源状态点（四态，形状 + 色双通道）**——状态永不只用颜色编码：

| 形状 | 色 | 含义 |
|---|---|---|
| `●` | status.success | 新鲜（最近一轮摄取成功且有新数据） |
| `○` | fg.faint | 无数据（该源未配置或无记录） |
| `◐` | status.warning | 陈旧（超过该源预期节奏未更新） |
| `!` | status.error | **有问题**（未验证格式版本 / 坏行 / 冲突，见 §9） |

点击任一状态点进入数据健康面板。

## 2. 配额油表（第一带 · 差异化组件）

[ADR-0008](../adr/0008-配额窗口.md) 论证油表是差异化第一位，信息架构却把它排在成本 KPI 之后——**本节把它放回第一带**。

**能力驱动的第一屏**：存在任何配额数据源时，油表占第一带、KPI 退居第二带；不存在时第一带直接是 KPI。不为没有数据的源留空位。

- **布局**：每个 `limit_key` 一行，最多 4 行，超出折叠为"另 N 项"。行结构：
  `源标识 + 限额名（13px fg.muted）` → `燃料条` → `主读数（28px Maple Mono）` → `燃烧率 + 重置时刻（12px fg.muted）`
- **燃料条**：高 `gauge.bar.h`，圆角 `gauge.bar.r`，轨道 bg.raised，填充 accent.solid；宽度按容器伸展，不设固定宽
- **溯源决定形态**（三种不可混排，这是 ADR-0008 的硬约束在视觉上的落地）：

| provenance | 条的形态 | 主读数 |
|---|---|---|
| `official` | 实心填充 | 百分比 + 剩余时间，如 `62% · 2h14m 后重置` |
| `local-estimate` | **描边 + 斜纹填充**（非实心） | **不出百分比**：`observedUsage + unit`，副行给燃烧率，如 `1.84M tokens · 412K/h` |
| `user-configured` | 实心填充 + 虚线描边 | 百分比 + `按你配置的容量` 标注 |

- **将尽提示**：剩余 < 15% 或 < 20 分钟时，条转 status.warning 并在读数前加 `!` 图标（色觉冗余，不靠颜色单通道）。**不加任何额外动效**——快没油时该做的是让人看清，不是表演。
- **无窗口信息时**：只画燃烧率与近 5 小时活动量，条降级为一条活动 sparkline，明示"该源不提供窗口信息"
- **TUI**：单行 braille 条 `⣿⣿⣿⣿⣶⣀⣀⣀` + 同样的读数与溯源标注文字
- **桌面 Widget**：仅显示优先级最高的一条（用户可选），单条 + 读数

## 3. KPI 行

- 结构：指标名（`kpi.label` 字号 fg.muted，平白中文如"今日 Tokens"）→ 读数（`kpi.value` Maple Mono tabular fg.primary）→ 环比（12px，方向箭头 + %，fg.muted；方向有歧义时无颜色）→ sparkline（可选，高 `kpi.spark.h`，accent.muted 细线）
- **容器：无卡片**。指标直接排在 `bg.canvas` 上，项间用发丝竖线分隔——克制优先于"卡片感"
- 成本读数 `$12.80`，token 读数紧凑记数 `3.4M`，悬停 tooltip 出完整精度
- 加载：等形骨架（读数位置一块 bg.raised 圆角矩形，1.2s 呼吸），不转圈

## 4. 趋势图（ECharts 6 · 模块化懒加载）

- 单系列 = accent.solid 2px 线；多系列 = chart.series 顺序取色；面积填充**禁用**
- 网格仅水平，fg.faint alpha 0.08；轴线不画
- 轴标签 `chart.axis` 字号 fg.muted；x 轴日期 `MM-DD`，y 轴紧凑记数
- hover：十字线（fg.faint）+ tooltip（bg.overlay + border.hairline，逐系列列值，Maple Mono）
- 时间范围切换 = 250ms 交叉淡化，不重挂载；主题切换须与页面同帧（见[动效规格](动效规格.md)）
- 每图配文本摘要 + 表格等价物（无障碍硬要求）
- TUI 版：braille 渲染同一数据，单 accent 色

## 5. 热力图（签名对象 · 最高优先级）

- **Web**：53×7 CSS Grid，单元格 `heat.cell`，圆角 `heat.cell.r`，间距 `heat.cell.gap`；heat[0..4] 填色；空格 = heat[0] 中性色非纯黑
- **标定窗口 = 显示窗口**（修正）：显示 53 周就用这 53 周的数据标定。原文用"90 天 p95"标定一年格子，会稳定产出两种失真——三个月前用量更大的用户，早期格子全部撞满档，一年节奏压成一块实心；最近才重度使用的用户，早期全是空档。
- **分档函数 = 显示窗口内非零日的分位数切分**（新增，原文未定义）：

| 档 | 区间 |
|---|---|
| heat[0] | 该日无活动（值为 0） |
| heat[1] | (0, p50] |
| heat[2] | (p50, p75] |
| heat[3] | (p75, p90] |
| heat[4] | (p90, ∞) |

  分位数在**非零日集合**上计算。token 日用量是强右偏分布，线性切分会把绝大多数格子压进 heat[1]，热力图变成"几乎全暗 + 几个亮点"——签名对象毁在这一步上是最不值得的。
- hover 单元格：tooltip 精确值 `2026-07-14 · 2,184,220 tokens · $4.17`
- 月份标签 `heat.label` 字号 fg.faint；星期标签只标 一 / 四
- **数据来源**：永久层 `daily_usage_rollups`，因此热力图不受事件保留窗口影响（[ADR-0011](../adr/0011-存储生命周期.md)）
- **TUI**：同数据 braille / 半块字符渲染，accent 单色 + 明度分档。**braille 密度映射**：braille 单元 2×4 共 8 点，取点数 {0,1,2,4,6} 对应 heat[0..4]，点位按固定模板自下而上填充（不随机）；truecolor 可用时叠加明度，16 色降级时只靠密度
- **桌面 Widget**：迷你版 26×7，无标签，点击打开完整窗口
- **验收**：五档 ΔL 均匀、空格不抢戏、三端同源数据、真实右偏数据下五档均有分布——这是品牌对象，按最高标准 review

## 6. 维度表格（源 / 模型 / 智能体 / 项目 / 会话 / 事件下钻）

下钻维度链含**智能体**（[ADR-0018](../adr/0018-开放源集与智能体维度.md)）：无智能体数据的源在该级自动跳过（能力降级，不留空层）。

- 行高 `table.row.h`，斑马纹禁用；行 hover = fg.primary alpha 0.05
- 数字列右对齐 Maple Mono tabular；文本列左对齐；表头 `table.head` 字号 fg.muted，全小写不加大写跟踪
- 每行末尾成本列后跟随行 mini bar（占该行最大值比例，accent.muted 高 `table.bar.h`）——不用第二色相
- 点击行 = 下钻，进出动效见[动效规格](动效规格.md)（下钻 200ms 生长 / 返回 120ms 逆向收回）
- 不分页，用虚拟滚动
- **超出保留窗口的下钻形态**（新增）：事件层按 `retention.events_days` 滚动，窗口外只有会话汇总与日聚合。下钻到超窗区间时，事件层不显示空表，而显示一行说明 + 一个动作：
  `该时间段的事件明细已按保留策略清理（当前保留 180 天）。会话与日汇总仍然完整。` + `调整保留期` 链接到设置。
  **不掩饰、不假装加载中**——这是[ADR-0011](../adr/0011-存储生命周期.md)承诺边界的诚实呈现处。

## 7. 时间范围分段控件

- 段：24h / 7d / 30d / 90d / 自定义；容器 bg.raised 圆角 6px 内聚 2px
- 激活段 = bg.overlay + fg.primary；未激活 fg.muted；切换 100ms 滑动指示块（transform）
- 自定义 = 弹出日期范围选择（bg.overlay 浮层，React Aria 日期范围）

## 8. 设置界面（新增）

它是 [ADR-0010](../adr/0010-配置子系统.md) 配置面的 UI 投影，**不引入配置面之外的项**。分区与配置文件段落一一对应：

| 分区 | 内容 |
|---|---|
| **数据源** | 每源一行：状态点 · 数据根 · 启用开关 · 最近扫描 · 事件数 · 错误计数。多通道源额外给**权威通道单选**（R3 的落地面：非权威通道照常入库但不进聚合，此处必须说清"选它意味着什么"） |
| **外观** | 主题（含已安装用户主题）· 深浅模式 · 语言 · **时区**（system 或锁定 IANA 时区；切换时提示"窗口内历史将重算，窗口外保留原口径"） |
| **数据** | 保留期两项（观测 / 事件）· 数据库体积与各层行数 · `压缩清理` 动作 · 数据目录路径 |
| **定价** | 远程刷新开关 · 覆盖文件路径 · 当前定价表版本与抓取时间 |
| **关于** | 版本 · 检查更新 · 日志目录 · `运行诊断`（等价于 `tokly doctor`） |

- 表单控件全部 React Aria；任何改动**即时校验、显式保存**，不做自动保存（配置错误会拒绝启动，静默保存会让人失去挽回机会）
- 校验失败：错误指到具体字段并给出原因，与 CLI 的 `tokly config check` 输出同一套文案

## 9. 数据健康面板（新增）

`conflict_observations` 与 `ingest_errors` 是"失败可见性"的全部机制，此前可见性只到数据库层——用户永远看不到"有 N 条坏行被跳过"。本面板是 `tokly doctor`（[ADR-0014](../adr/0014-诊断与格式演进.md)）的 UI 形态，**同一份数据两种呈现**。

- 顶部一行结论：`一切正常` 或 `3 个源有 2 类问题`
- 逐源分组，每组给：格式版本（含"未验证"标记）· 水位线位置与代际 · 最近事件时间 · 坏行计数 · 冲突计数 · 未匹配定价计数
- **未验证格式版本**是最高优先项：`检测到 Codex 的新格式版本 0.2x，该部分用量未计入`——它意味着数字在变少而不是变错，必须让人看见
- 冲突项可展开为清单：事件身份 · 冲突类型 · 两侧的流与位置 · 保留了哪一侧。**不展示 payload 内容**（只存指标的红线）。冲突分两档（2026-08-04 阶段二裁决：全配对闭包的展示层对冲）：**当前仍冲突**（各流现行终态仍异）置顶；**历史已收敛**（终态已一致，如良性 fork 的中间草稿对）默认折叠——查询期由终态比较派生，不加列
- 每项配一个动作：重扫该源 / 打开源目录 / 复制诊断报告

## 10. 首次运行（新增）

产品的全部价值是"一次导入看到全部历史"，这是第一印象时刻，此前只有一句"运行 `tokly scan`"的空态。

三步，全程不阻塞、不要求输入：

1. **发现**：逐源出现在列表里，实时滚动计数 `Claude Code · 2,384 个文件 · 141,830 条`。发现不到的源灰显并给一句原因（"未检测到数据目录"）。
2. **摘要**：`导入完成 · 6 个源 · 312,904 条事件 · 覆盖 2025-04 至今 · 数据库 84 MB`。同时给出本次的 `excluded` 与坏行计数（有就说，没有就不提）。
3. **进入概览**：此时且仅此时播放热力图入场（签名时刻）——用户第一次看到自己一年的节奏，正好落在这里。

CLI 与 TUI 走同结构的文本版本。**不做多步向导、不做账号、不做偏好问卷**——本地工具的最好开场是它已经知道答案了。

## 11. 状态与溯源

- **骨架屏**：与布局等形的 bg.raised 块，1.2s 呼吸；禁用 spinner
- **空态**：一句具体指引 + 一个动作，例：`还没有数据。运行 tokly scan 导入你的第一个数据源。` fg.muted 14px 居中，无插画无 emoji
- **错误态**：fg.muted 说明 + status.error 圆点 + 图标 + 重试按钮；溯源标注照常显示
- **溯源标注**（五档，新增第五档）：成本数字旁 `provenance.label` 字号 fg.faint，hover 解释口径。

| 标注 | 含义 |
|---|---|
| `官方` | provider 账单或官方 API 数据 |
| `工具自算` | 源工具自己算的（如 OpenCode 按 models.dev），**不是账单** |
| `计算值` | Tokly 按事件时点生效价计算 |
| `计算值（价目回溯不可得）` | 事件早于本机最早价目快照，按最早快照计价（[ADR-0015](../adr/0015-计价精度.md)），与正常计算值视觉可区分 |
| `估算` | token 本身是估算（如 Cursor） |

  native 与 computed 双列并存时按 `displayPolicy` 分别展示差异（如"OpenCode 自算 $312 · Tokly 计算 $891"），**不得合并为单一"总成本"**。会话汇总若只有部分事件有某口径，读数旁标 `部分`（对应 `sessions.has_partial_cost`）。

## 11·五、新鲜度三态（ADR-0019）

实时刷新的界面必须能区分"数据是新的"和"数据看起来像新的"。三态在 UI 上不可混同：

| 态 | 判据 | 表现 |
|---|---|---|
| **新鲜** | 已收到 ≥ 当前 `data_version` 的数据 | 正常，无任何附加标记 |
| **重取中** | 已知有更新版本、新数据尚未到 | **保持旧值** + 顶栏一处细微进行中指示；**禁止骨架屏、禁止闪烁**——数据仍然有效，只是不是最新 |
| **陈旧** | 事件流断开超阈值 / daemon 不可达 / 只读降级 / 摄取已停 | 顶栏明确标注 `数据可能过期 · 最后更新 14:32`，**不伪装成实时**；数据源状态点转 `◐` 陈旧态 |

- 三态的判据全部来自 `data_version` 与事件流存活，不靠猜；
- 摄取停止（所有权失效，ADR-0012）走陈旧态同一条展示路径，不另造形态；
- 数据级联（[编排规格](编排规格.md) §四）只在**同一 `data_version`** 内编排——跨版本的数据不同帧呈现。

## 12. i18n 布局适应（新增）

中英文长度差异会改变布局，此前无任何规格。

- **指标名与表头**：按最长语言预留宽度，不允许换行也不允许截断——两种语言各出一版视觉稿核对
- **KPI 读数**：数字格式与语言无关（`3.4M` / `$12.80`），读数区宽度固定，不随语言变化
- **TUI 状态栏与表头**：按 en 与 zh-CN 分别做 80 列布局校验，两者都不崩才算过
- **日期**：zh-CN `2026/08/03`，en `Aug 3, 2026`；两侧格式由共享测试向量对齐（[ADR-0016](../adr/0016-i18n运行期.md)）
- 技术名词不译（token / cache / session / 模型名），双语共同约定

## 13. TUI 专规

- 单线边框，标题嵌上边框（`┌─ 模型用量 · 近 90 天 ──┐`）；焦点面板边框 accent，非焦点 fg.faint
- 底部常驻状态栏：`Opus · 12.4K tokens · $0.04 · 3.2s`（Maple Mono，accent 仅用于模型名）
- 键位提示在状态栏右侧 fg.faint：`q 退出 · t 主题 · r 刷新 · d 诊断`
- 无 emoji；状态字符 `✓ ✗ ! ○ ◐ ●`（与 Web 状态点同一套语义词汇）；数字右对齐
- **80 列降级规则**（补全）：列按优先级排序 —— 时间 > 模型 > 总 token > 成本 > output > cache；宽度不足时**从右向左整列丢弃**，不压缩列宽也不截断数字。最小可用宽度 60 列，低于此显示单行摘要模式
- **重绘节流**（新增）：实时视图最高 10 fps（100ms 合并帧），无变化不重绘；单次重绘只 flush 变更区域。TUI 的"卡"几乎全部来自无节制全屏重绘
- **TUI 完成度清单**（对标 Web 六态）：焦点态可见 · 全键盘可达 · 无数据 / 加载 / 错误三态齐全 · 降级态明示（只读直连时状态栏标注）· 主题切换后焦点与滚动位置保持 · TestBackend 快照覆盖三种终端宽度

## 14. 桌面 Widget（可钉）

- 默认 `widget.w` × `widget.h`，bg.canvas alpha 0.95（系统级圆角与阴影交给 OS）
- 内容：优先级最高的一条配额油表 + 今日读数（`kpi.value`）+ 迷你热力图；无导航无控件
- 置顶钉住、点击任意处打开完整窗口；主题跟随桌面端设置
- 数值变化时一次 150ms 呼吸（功能性反馈，非签名时刻）

## Tier 3 尺寸登记表
