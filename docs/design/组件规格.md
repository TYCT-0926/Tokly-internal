# 组件视觉规格（三端）

通用纪律见 ../设计原则.md（禁止清单、动效、验收清单）。此处只写组件级规格。间距/字号/色值一律引用令牌，禁止组件内出现字面量。

## 1. 布局壳（Web / 桌面窗口）

- 左侧导航 240px，`bg.canvas`，右缘 `border.hairline`；无 logo 块，顶部仅产品名（fg.secondary 13px）
- 导航项：14px fg.secondary；激活 = `state.active.bg` 背景 + 左缘 2px accent.solid；hover = bg.raised
- 内容区最大宽度 1200px，左右 padding 32px，垂直节奏 24px
- 顶栏右侧：时间范围分段控件 + 主题切换 + 数据源状态点（每源一个：绿=新鲜 / 灰=无数据 / 黄=陈旧）

## 2. KPI 卡（第一屏）

- 结构：指标名（13px fg.muted，平白中文如"今日 Tokens"）→ 读数（28px Maple Mono tabular fg.primary）→ 环比（12px，方向箭头+%，fg.muted；方向有歧义时无颜色）→ sparkline（可选，高 24px，accent.muted 细线）
- 容器：无卡片！指标直接排在 `bg.canvas` 上，项间用发丝竖线分隔——克制优先于"卡片感"
- 成本读数格式 `$12.80`，token 读数紧凑记数 `3.4M`，悬停 tooltip 出完整精度
- 加载：等形骨架（读数位置一块 bg.raised 圆角矩形，1.2s 呼吸），不转圈

## 3. 趋势图（uPlot）

- 单系列 = accent.solid 2px 线；多系列 = chart.series 顺序取色；面积填充**禁用**
- 网格：仅水平，fg.faint alpha 0.08；轴线不画
- 轴标签：11px fg.muted，x 轴日期 `MM-DD`，y 轴紧凑记数
- hover：十字线（fg.faint）+ tooltip（bg.overlay + border.hairline，逐系列列值，Maple Mono）
- 时间范围切换 = 150ms 交叉淡化，不重挂载
- TUI 版：braille 渲染同一数据（⣿ 系点阵），单 accent 色

## 4. 热力图（签名对象 · 最高优先级）

- Web：53×7 CSS Grid，单元格 10px、圆角 2px、间距 2px；heat[0..4] 填色；空格=heat[0] 中性色非纯黑
- 标定：按用户自身 90 天峰值分位（p95）相对分档，保证任何人都有满档色
- hover 单元格：tooltip 精确值 `2026-07-14 · 2,184,220 tokens · $4.17`
- 月份标签 11px fg.faint，星期标签只标 一/四
- TUI：同数据 braille/半块字符渲染，accent 单色 + 明度分档
- 桌面 Widget：迷你版（26×7），无标签，点击打开完整窗口
- **验收**：五档 ΔL 均匀、空格不抢戏、三端同源数据——这是品牌对象，按最高标准 review

## 5. 维度表格（模型/项目/会话下钻）

- 行高 36px，斑马纹禁用；行 hover = fg.primary alpha 0.05
- 数字列右对齐 Maple Mono tabular；文本列左对齐；表头 12px fg.muted 全小写不加大写跟踪
- 每行末尾成本列后跟随行 mini bar（占该行最大值比例，accent.muted 2px 高）——不用第二色相
- 点击行 = 下钻（模型→项目→会话→事件），行级 150ms 展开过渡
- 分页不用，用虚拟滚动（本地数据无延迟，滚动即全部）

## 6. 时间范围分段控件

- 段：24h / 7d / 30d / 90d / 自定义；容器 bg.raised 圆角 6px 内聚 2px
- 激活段 = bg.overlay + fg.primary；未激活 fg.muted；切换 100ms 滑动指示块（transform）
- 自定义 = 弹出日期范围选择（bg.overlay 浮层）

## 7. 状态

- **骨架屏**：与布局等形的 bg.raised 块，1.2s 呼吸（opacity 0.6↔1），禁用 spinner
- **空态**：一句具体指引 + 一个动作。例：`还没有数据。运行 tokly scan 导入你的第一个数据源。` fg.muted 14px 居中，无插画无 emoji
- **错误态**：fg.muted 说明 + error 色小圆点 + 重试按钮；溯源标注照常显示（如"该数据源为估算值"）
- **溯源标注**：成本数字旁 fg.faint 11px 标签，hover 解释口径。口径四档：`官方`（provider/官方 API 数据）/ `工具自算`（如 OpenCode 按 models.dev 计算，非账单）/ `计算值`（Tokly 定价表计算）/ `估算`。native 与 computed 双列并存时按 displayPolicy 展示差异（如"OpenCode 自算 $312 · Tokly 计算 $891"），不得合并为单一"总成本"

## 8. TUI 专规

- 单线边框，标题嵌上边框（`┌─ 模型用量 · 近 90 天 ──┐`）；焦点面板边框 accent，非焦点 fg.faint
- 底部常驻状态栏：`Opus · 12.4K tokens · $0.04 · 3.2s`（Maple Mono 等价等宽，accent 仅用于模型名）
- 键位提示在状态栏右侧，fg.faint：`q 退出 · t 主题 · r 刷新`
- 无 emoji；状态字符 `✓ ✗ ! ○`；数字右对齐；80 列不崩（表格列按优先级丢弃：先丢 cache 再丢 output）
- 动效仅限 braille spinner 与进度条；视图切换无转场

## 9. 桌面 Widget（可钉）

- 默认 280×160，bg.canvas alpha 0.95（系统级圆角与阴影交给 OS）
- 内容：今日读数（28px Maple Mono）+ 迷你热力图 + 状态栏一行；无导航无控件
- 置顶钉住、点击任意处打开完整窗口；主题跟随桌面端设置
