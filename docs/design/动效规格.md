# 动效与交互规格

顶级体验 = 交互完成度 × 动效纪律。动效的目标不是"炫"，是**让用户感到这台仪器是活的、且完全受控**。所有规则与 设计原则.md（公开仓）一致，此处是实现级参数。

## 分层与技术选型

| 层 | 用于 | 技术 |
|---|---|---|
| 微交互 | hover / focus / pressed / 状态切换 | CSS transition（100–150ms） |
| 组件级 | 可中断、可取消的程序化动画 | WAAPI |
| 签名时刻 | 热力图入场、下钻过渡、Widget 待机 | Motion for React（LazyMotion strict，仅 domAnimation） |
| 图表内 | 系列切换、时间范围变更 | ECharts Universal Transition（≤300ms） |
| TUI | 无转场，仅 braille spinner / 进度条 | Ratatui（无动画层，重绘即新帧） |

## 全局令牌

```css
--tokly-dur-instant: 100ms;   /* hover/pressed 即时反馈 */
--tokly-dur-fast:    150ms;   /* 状态切换 */
--tokly-dur-base:    250ms;   /* 入场/过渡 */
--tokly-ease-out:    cubic-bezier(0.16, 1, 0.3, 1);  /* 入场唯一曲线 */
--tokly-ease-std:    cubic-bezier(0.4, 0, 0.2, 1);   /* 状态互切 */
--tokly-spring-ui:   stiffness 380, damping 32, mass 0.9;  /* 签名弹簧：利落，不弹 */
```

- 只动 `transform` / `opacity`；禁 `transition: all`；退出快于进入（进入 ×0.6）
- 帧预算：动画期主线程 ≤16.7ms；输入反馈（点击/按键到视觉响应）<50ms
- `prefers-reduced-motion`：保留 150ms 淡入，移除全部位移/弹簧/stagger

## 逐交互规格

| 交互 | 动效 | 参数 |
|---|---|---|
| 主题切换 | 全量 CSS 变量交叉淡化，无布局位移 | 150ms，禁用过渡期间的元素级动画 |
| 时间范围切换 | 分段指示块滑动 + 图表数据交叉淡化（不重挂载） | 块 150ms transform；图 250ms crossfade |
| 下钻（模型→项目→会话） | 新层级自触发点生长：fade + scale(0.98→1)，transform-origin 在触发行 | 200ms ease-out；返回 120ms |
| 热力图首次入场（**签名**） | 按周列 stagger 淡入，每列 8ms，总量封顶 500ms；悬停单元格 tooltip 150ms 淡入 | Motion spring `--tokly-spring-ui`；之后入场不再播（只首次） |
| KPI 数值更新 | **禁止滚动计数**；旧值淡出/新值淡入 | 150ms crossfade |
| 骨架屏 | bg.raised 块呼吸 | opacity 0.6↔1，1.2s 循环；数据到达后 150ms 整体淡入替换 |
| 对话框/浮层 | scale(0.95→1) + fade，transform-origin 在触发元素 | 入 150ms / 出 100ms；焦点圈定与关闭恢复（React Aria 负责） |
| 通知 toast | 自底缘滑入 8px + fade | 入 200ms spring / 出 120ms |
| 焦点环 | 出现 | 100ms fade，无位移 |
| 表格行 hover | 底色淡入 | 100ms（4–6% alpha） |

## 签名时刻（个性预算的三个去处）

1. **热力图首次入场**（上文）——用户第一次看到自己一年的 token 节奏，值得 500ms 的仪式感
2. **下钻的"缩放飞入"**——从图表到明细的空间连续感，信息层级靠动效讲清楚
3. **桌面 Widget 待机**——数值变化时的一次 150ms 呼吸，安静但有生命

除此之外一切安静。**任何新动效必须申请预算**：在 PR 描述中说明它帮用户理解了什么。

## ECharts 使用纪律

- 仅开 Universal Transition（系列切换）；**入场动画关闭**（图表不该每次刷新都表演）
- tooltip/axisPointer 跟随 100ms 内；dataZoom 拖动实时（无惯性溢出）
- 每图配文本摘要 + 表格等价物（无障碍硬要求）

## 交互完成度清单（每组件必过，React Aria 承担大部）

- [ ] default / hover / focus-visible / active / disabled / loading 六态
- [ ] 键盘全流程可操作；焦点顺序符合视觉顺序；弹层关闭焦点恢复触发元素
- [ ] 触控/鼠标/键盘三输入一致（React Aria 统一）
- [ ] aria 标签与角色正确；图表有文本摘要；状态变化有 aria-live（数值更新不打扰）
- [ ] 本地数据无 spinner：首屏骨架 ≤1 次，之后全部即时
- [ ] `prefers-reduced-motion` 通过；Windows/macOS/Linux 截图比对通过

## 验收与质量门

- 视觉回归：关键组件三平台截图 diff 进 CI
- 帧预算抽查：热力图入场、下钻、范围切换三场景录屏数帧（允许个别掉帧，不允许连续 >2 帧超 16.7ms）
- 设计验收清单（设计原则.md）+ 本规格逐项过 PR
