# 动效与交互规格

顶级体验 = 交互完成度 × 动效纪律。动效的目标不是"炫"，是**让用户感到这台仪器是活的、且完全受控**。规则与公开仓 `docs/设计原则.md` 一致，此处是实现级参数。

> **2026-08-03 四轮修订**（依据 [审查-2026-08-03](../research/审查-2026-08-03.md)）：三处补齐、一处对齐。
> ① 技术选型改为**平台原生优先，移除 Motion for React**（[ADR-0009](../adr/0009-运行期基线.md) 抬高运行期基线后它不再有不可替代能力）；
> ② 补**感知层三条**——同时性、打断语义、方向对称，原文只有物理层参数；
> ③ 验收从人工抽查改为**可执行门禁**；
> ④ 「签名时刻」由三个收敛为**一个**，与设计原则的"个性预算只允许一个"对齐（原文 1 对 3 矛盾）。

## 分层与技术选型

| 层 | 用于 | 技术 |
|---|---|---|
| 微交互 | hover / focus / pressed / 状态切换 | CSS transition（100–150ms） |
| 浮层出入 | 对话框、tooltip、日期选择 | `@starting-style` + `transition-behavior: allow-discrete`（无需 JS 管理挂载态） |
| 组件级 | 可中断、可取消的程序化动画 | WAAPI |
| 弹簧 | 需要"利落但有质感"的单一曲线 | **构建期由令牌管线生成的 `linear()` 缓动**，非运行期计算 |
| 层级过渡 | 下钻与返回 | View Transitions（可用时）→ WAAPI 等价路径（回落） |
| 图表内 | 系列切换、时间范围变更 | ECharts Universal Transition（≤300ms） |
| TUI | 无转场，仅 braille spinner / 进度条 | Ratatui（无动画层，重绘即新帧） |

**没有 JS 动画库。** 三个动效场景（stagger、层级过渡、状态呼吸）全部只动 `transform` / `opacity`，用 CSS 与 WAAPI 各十余行即可；唯一需要库的能力是弹簧曲线，而弹簧可以在构建期编码成 `linear()`。合成器驱动的原生动画不受主线程阻塞，这本身就是帧预算的一部分。

## 全局令牌

```css
--tokly-dur-instant: 100ms;   /* hover/pressed 即时反馈 */
--tokly-dur-fast:    150ms;   /* 状态切换 */
--tokly-dur-base:    250ms;   /* 入场/过渡 */
--tokly-ease-out:    cubic-bezier(0.16, 1, 0.3, 1);  /* 入场唯一曲线 */
--tokly-ease-std:    cubic-bezier(0.4, 0, 0.2, 1);   /* 状态互切 */
--tokly-spring-ui:   linear(…);  /* 由 stiffness 380 / damping 32 / mass 0.9 在构建期采样生成 */
```

`--tokly-spring-ui` 的生成规则：`tokly-tokens` 按上述弹簧参数以固定步长采样至静止（位移变化 < 1e-3 且速度 < 1e-3），输出 `linear()` 停靠点与对应时长，与其他令牌同批产出（[ADR-0017](../adr/0017-令牌派生引擎.md)）。**弹簧参数是令牌，不是散落在组件里的魔法数。**

- 只动 `transform` / `opacity`；禁 `transition: all`；退出快于进入（进入 ×0.6）
- 帧预算：动画期主线程 ≤16.7ms；输入反馈（点击/按键到视觉响应）< 50ms
- `prefers-reduced-motion`：保留 150ms 淡入，移除全部位移、弹簧与 stagger

## 感知层三条（本次新增）

物理参数（时长、曲线）只决定单个动效好不好看；下面三条决定**一屏动效合起来是否受控**。

### 1. 同时性上限

一次用户操作最多允许**两个并发动效层**：主体（被操作对象的变化）+ 反馈（指示器、tooltip、焦点环）。stagger 计为一层。

系统触发的更新（SSE 推送的数据刷新）**不得与用户触发的动效叠加**：用户动效优先，系统更新排队至其结束，超过 400ms 未结束则直接跳到终值不做过渡。理由：数据自己动和用户让它动，在感知上是两件事，同时发生就是噪音。

### 2. 打断语义

所有动效**可被同类操作打断**，打断行为统一为：**从当前计算值出发，以剩余时长的 60% 走向新目标**。不反弹、不跳变、不排队。

实现口径：WAAPI 用 `commitStyles` 固定当前值后起新动画；CSS transition 天然从当前值继续，只需保证目标值切换不重挂载元素。

这是"感到完全受控"与"感到卡"的分界线——跳变让人觉得程序在跟自己抢，排队让人觉得程序没听见。

### 3. 方向对称

有空间语义的动效必须**双向对称**：下钻从触发点生长（200ms），返回**沿同一 `transform-origin` 收回**（120ms），而不是淡出。返回时的方位感是空间连续性的另一半，只做进不做退等于把用户放在原地。

## 逐交互规格

| 交互 | 动效 | 参数 |
|---|---|---|
| 主题切换 | 全量 CSS 变量交叉淡化，无布局位移 | 150ms；过渡期间禁用元素级动画。**图表必须与页面同帧完成**（见下节） |
| 时间范围切换 | 分段指示块滑动 + 图表数据交叉淡化（不重挂载） | 块 150ms transform；图 250ms crossfade |
| 下钻 / 返回 | 下钻自触发点生长：fade + scale(0.98→1)；返回沿同一 origin 收回 | 下钻 200ms ease-out；返回 120ms（逆向，非淡出） |
| 热力图首次入场（**签名时刻**） | 按周列 stagger 淡入，每列 8ms，总量封顶 500ms | `--tokly-spring-ui`；仅首次，之后不再播 |
| 热力图单元格 hover | tooltip 淡入 | 150ms |
| KPI 数值更新 | **禁止滚动计数**；旧值淡出 / 新值淡入 | 150ms crossfade |
| 配额油表数值变化 | 燃料条长度过渡 + 读数 crossfade | 条 250ms ease-out；读数 150ms。**将尽阈值触发时不加额外动效**，用状态色与图标（色觉冗余） |
| 骨架屏 | bg.raised 块呼吸 | opacity 0.6↔1，1.2s 循环；数据到达后 150ms 整体淡入替换 |
| 对话框 / 浮层 | scale(0.95→1) + fade，origin 在触发元素 | 入 150ms / 出 100ms；`@starting-style` 承担入场，焦点圈定与恢复由 React Aria 负责 |
| 通知 toast | 自底缘滑入 8px + fade | 入 200ms（`--tokly-spring-ui`）/ 出 120ms |
| 焦点环 | 出现 | 100ms fade，无位移 |
| 表格行 hover | 底色淡入 | 100ms（4–6% alpha） |
| 桌面 Widget 数值变化 | 一次 150ms 呼吸 | 安静的状态反馈，非签名时刻 |

## 图表与主题切换的同帧要求

令牌系统承诺「主题切换 = 根元素换 `data-theme`，无闪烁、无 JS 重渲染」。**canvas 渲染的图表不受 CSS 变量影响**，若不处理，页面已变色而图表晚半拍跳变——这正是廉价感的来源。

两条路径，在 M0.5 spike ② 定格（[ADR-0001](../adr/0001-技术栈与运行时.md)）：

1. **首选 SVG 渲染器**：图表输出为 DOM，随 CSS 变量一同变色，零 JS、天然同帧。风险是 dataZoom 拖动性能，须按真实数据量级实测。
2. **回落 canvas + 过渡编排**：图表容器在主题切换时走 150ms 淡出淡入，`setOption` 在不透明度最低点执行。确定可行，代价是手写编排。

**验收标准（无论走哪条）**：主题切换时，图表与页面其余部分的视觉变化落在同一 150ms 过渡窗口内，录制帧中不存在"页面已变、图表未变"的中间帧。

## 签名时刻（个性预算：一个）

**热力图首次入场**是全产品唯一的签名时刻——用户第一次看到自己一年的 token 节奏，值得 500ms 的仪式感。

原文列的另外两项**从个性预算中移出**，因为它们服务的是理解与反馈，不是个性：

- **下钻的空间连续**——功能性动效，讲清信息层级从哪来到哪去；
- **Widget 状态呼吸**——功能性反馈，告诉用户数值变了。

这个收敛使本规格与设计原则的"整个产品只允许一个精心设计的签名时刻"一致（原文 1 对 3，是本次审查发现的矛盾）。

除此之外一切安静。**任何新动效必须申请预算**：在 PR 描述中说明它帮用户理解了什么；说不出来就不加。

## ECharts 使用纪律

- 仅开 Universal Transition（系列切换）；**入场动画关闭**——图表不该每次刷新都表演
- tooltip / axisPointer 跟随 100ms 内；dataZoom 拖动实时，无惯性溢出
- 每图配文本摘要 + 表格等价物。**这是硬要求，与 ECharts 自带的 `aria.enabled` 无关**——后者生成的是自动描述，不能替代结构化等价物

## 交互完成度清单（每组件必过，React Aria 承担大部）

- [ ] default / hover / focus-visible / active / disabled / loading 六态
- [ ] 键盘全流程可操作；焦点顺序符合视觉顺序；弹层关闭焦点恢复触发元素
- [ ] 触控 / 鼠标 / 键盘三输入一致
- [ ] aria 标签与角色正确；图表有文本摘要与表格等价物；状态变化有 aria-live 且不打扰
- [ ] 本地数据无 spinner：首屏骨架 ≤1 次，之后全部即时
- [ ] 同时性、打断、方向对称三条逐项自查
- [ ] `prefers-reduced-motion` 通过；三平台截图比对通过

## 验收与质量门（从人工抽查改为可执行门禁）

原文的「录屏数帧」不可能持续执行，「30 分钟无视觉疲劳」不可测量。规则不变，执行方式改为机器可判：

| 规则 | 门禁 |
|---|---|
| 只用 transform / opacity 过渡；禁 `transition: all` | **Stylelint 自定义规则**，CI 强制 |
| 时长必须取自三档令牌 | Stylelint：`transition-duration` / `animation-duration` 只允许令牌变量 |
| 不允许连续 >2 帧超 16.7ms | **Playwright trace** 采集三场景（热力图入场、下钻、范围切换）的 frame timing 并断言 |
| 主题切换图表同帧 | Playwright 逐帧截图，断言无"页面已变、图表未变"的中间帧 |
| 禁止清单（渐变 / 玻璃 / emoji / 大圆角 / 重阴影） | Stylelint + 源码扫描：非白名单位置的 `linear-gradient`、`backdrop-filter`、emoji 码点、`border-radius > 12px`、`box-shadow` blur > 24px |
| 视觉回归 | 关键组件三平台截图 diff 进 CI |

**把品味变成 lint 是这份规格能被长期执行的唯一方式**，也是最有效的反 AI 味机制——自动生成的前端代码最先撞的就是禁止清单那几条。人工评审只保留一项：热力图作为品牌对象的主观验收。
