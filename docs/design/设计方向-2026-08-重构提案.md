- 状态：**accepted**（2026-08-04 维护者授权："我不会描述前端和高级的词汇，你深度思考，设计最优"——设计裁量权委任编排者，判决表 D1-D18 即日生效；维护者保留对**成图**的否决权，即任何样张/成品看图即可推翻，无需设计语言）

- 证据：五参考项目**源码级**考察（tokscale / codeburn / openusage / AIUsage / TokenTracker，本地克隆）+ 场外检索（ratatui showcase、暗色系设计趋势、雷达图批评文献）；可看样张在 `design/探索/`

## 一、诊断：现有界面为什么不行

1. **守则被误读**。「仪器=安静」被执行成「空」：三 KPI 等分栅格（守则症状 #3 的原样再现）、240px 侧栏装 3 个词、页面下半空白。真实仪器是**致密且通电**的——示波器的迹线会发光。
2. **令牌系统欠力**，排版救不回来：`chart-series-2/4` 纯灰在近黑底上隐形；`chart-grid` α=0.08 等于没有；字号阶梯封顶 28px 做不出英雄读数；heat 中段三档同色相压成棕泥；TUI 趋势带用盲文点阵（稀疏 2×4 点）读如噪点。
3. **无渲染闭环**。执行者自评"全绿"即过，没人看过一张渲染图。已建立 headless Chrome 截图闭环并强制（D12）。

## 二′、二轮校准（2026-08-04 晚 · TokenTracker 深研）

维护者判 v4 仍不合格，指认参考为 **TokenTracker（tokentracker.cc）**——即此前对话中口述的「Tokly 的设计」。对其线上站 + 仓库做了源码级考察：

**实现事实**（`dashboard/`）：React 18 + Tailwind 3 + **three.js**（3D 热力图为真 WebGL，2D/3D 切换）+ react-router；自建 `oai-gray` 灰阶（OpenAI 风格中性系）；画布 `#080808` 真黑；字体 OpenAI Sans + SF Mono；display 阶 72px/700/-0.03em；侧栏支持折叠、分组眉标（GENERAL/TOOLS/ACCOUNT）、活跃项药丸、底部主题切换 + GitHub 星标；产品面：29 工具、2,200+ 模型计价、桌面挂件、菜单栏/托盘、桌面宠物彩蛋。

**高级感在这里的构成（回答维护者"什么才叫高级感"）**：

1. **字阶极差造层级**：72px/700 巨数 vs 10px 加宽眉标——层级靠尺寸对比，不靠颜色和框；
2. **单色纪律**：界面本体全灰阶；语义色只给钱（绿→我们改琥珀）；品牌色只进数据（份额条/图表/图标）；
3. **真黑与卡内呼吸**：#080808 画布 + 卡内 20-24px 内距——**密度在卡内，安静在卡间**；
4. **一致的物性**：同一圆角、同一描边（白 7%）、零投影零渐变——卡片阵不是罪，廉价默认样式才是；
5. **真实身份物**：品牌 logo、真数字、活数据；装饰为零。

镜面因此降级（D15）：用户要的"高级感"实体是这套，不是光效。

**TUI 校准：需求先行**（维护者："保证操作与方向的正确性，看清楚需求再设计"）。视觉稿冻结，先定操作契约，获批后再出新稿：

- **用户任务**（按频次）：T1 瞥今天用量 + 配额余量（秒级）；T2 盯实时消耗（会话进行中）；T3 追钱去哪了（模型/项目/智能体）；T4 查某日明细；T5 复制/导出；T6 主题/诊断。
- **视图与其回答的唯一问题**：Overview=现在烧多少、还剩多少；Models=谁贵；Agents=谁的哪个替身在烧；Daily=哪天多、为什么；Sessions=这次会话花了多少；Stats=长期习惯。
- **操作契约**：`1-6`/`←→`/`Tab` 切视图 · `↑↓ PgUp/Dn Home/End` 移动 · `Enter` 展开/下钻 · `Esc` 返回 · `/` 过滤 · `s` 排序循环 · `y` 复制行 · `e` 导出 CSV · `r` 刷新 · `t` 主题 · `d` 诊断 · `?` 帮助层 · `q` 退出。
- **状态规范**：任何视图必有——选中行反色、位置指示 `n-m/total`、>300ms 才出 spinner、空态一句指令、stale 常驻标注（ADR-0019 三态）。
- 视觉语言跟随 v5（真黑、单框卡、粗体大数、琥珀点缀、八分块图形），新稿待本清单获批后出。

样张：`探索/概览-方向v6.png` 为**现行方向**（v5=TokenTracker 忠实临摹供对照；v4 镜面路线已弃；三轮演进链 v4→v5→v6 完整保留）。v6 相对 v5：巨数升 80px 加暖白渐变、余烬地形取代小卡热力（D17）、来源卡加家族 spark 与单价（D18）、配额卡带判定色与投影刻度（D6）、活跃态全面琥珀化、暖黑面板。

## 三、视觉身份 v2：黑色玻璃上的精密仪器（D15 后部分条款让位于 §二′）

三支柱（演进不推翻——仪器还是仪器，但**通了电**）：

1. **密度**：一屏之内信息块数量对齐 codeburn（9 块级），空白只允许出现在带间呼吸，不允许成片；
2. **光**：镜面光学层（下表）；发光只属于**数据**（迹线、活点、当前值），不属于装饰；
3. **活性**：每屏至少一处活物（实时事件流 / live 脉冲点 / 倒计时），一个自称实时的产品不允许有全静态屏。

镜面层规范（进令牌，D2 获批后落 `tokly-tokens`）：

| 令牌 | 部位 | 实现约束 |
|---|---|---|
| `mirror.floor` | 页面底部地光 | `radial-gradient` 定底，accent 6–10% α，纯 CSS 静态 |
| `mirror.hero` | 英雄读数倒影 | 翻转副本 + 线性 mask，α ≤ 12% |
| `mirror.chart` | 主图轴下倒影 | 静态 SVG 二次引用翻转，α ≤ 8% |
| `glass.edge` | 面板玻璃上缘 | `inset 0 1px 0` 白 4–6% α |

护栏：全部纯 CSS/静态 SVG，**禁 backdrop-filter 大面积、禁 JS 驱动光效**；装饰层永远在内容之下、不参与对比度计算；`prefers-reduced-transparency` 整层关闭；TUI 无镜面（其对应签名 = live 脉冲点 + 渐变条）。

## 四、色彩系统修订（D1 细则）

- 来源色族（OKLCH 等 L≈0.74 等 C≈0.10 派生，**不是**原品牌色——是我们调过的和谐化版本）：claude=琥珀（身份锚）· openai/codex=鼠尾草 · gemini=石板蓝 · cursor=玫瑰 · opencode=青 · 其余=金 · 兜底=暖灰。来源内模型按明度阶（±10–14% L）区分，阶梯派生是确定性的（同 tokscale「deterministic model shades」）。
- ANSI16 映射：琥珀→yellow、鼠尾草→green、石板→blue、玫瑰→magenta、青→cyan、金→bright-yellow。**顺带修复阶段九存疑③**（16 色档 amber 全灰）。
- 浅色主题同族独立派生（L 反转非取反）。
- 纪律句入守则：**色相=类别，明度=数量**。heat、单源视图、进度条保持单色相。
- 来源色**不是唯一标签**（tokscale a11y 条款照抄）：任何用色区分处必有文字/位置冗余。

## 五、签名组件（跨端语汇，D2 获批后逐个进组件规格）

1. **英雄读数**：字号阶梯补 34/44/52；成本为主读数，tokens/calls/sessions/cache 为随行读数；带倒影。
2. **全宽来源占比条**：一根分段条 encode 全部来源份额，下接来源徽章行（字形符号 + 名 + % + n models）。
3. **配额尺**（D6 语义全集）+ **窗口归因**子行：`opus-5 38% ██ · sonnet 19% █ · haiku 4%`。
4. **配额雷达**（D3 护栏版，M3）。
5. **热力墙**（D4 重调）；下钻页做**每源一卡**热力（AIUsage 形态，各卡用该源色族）。
6. **活流**：最近事件表，新行高亮渐隐；TUI/Web 同构。

## 六、TUI 方案（阶段九-2）

- 结构：**常驻标签栏** `Overview · Models · Agents · Daily · Stats`（tokscale 形态）+ **常驻底栏**（总量 + 键位）；诊断视图保留在 `d`。
- 图形词汇：条/柱一律八分块 `▁▂▃▄▅▆▇█`（**弃盲文柱**——盲文稀疏点读如噪声，此为阶段九观感差的首因）；热力格用 `██` 双宽成正方；进度条 `█…▏` 亚字符收边（tokscale widgets.rs 手法）。
- Agents 视图：三级树 + 双行明细（第二行 in/out/cache-read/cache-write faint 注记）。
- Daily 视图 + hourly 剖面（tokscale 有 hourly/minutely；我们 M3 补 hourly，日内节奏是真实诉求）。
- 配额：判定色 + 投影刻度 `╎` + 归因子行；超限红字给**提前触顶时刻**。
- 预算不变：10fps 合帧、空闲零重绘、三档色彩降级链、80/60 列降级（这些是阶段九的真资产，全部保留）。

## 七、Web 方案（阶段七B 前置）

- 区带重排见样张 `探索/概览-方向v4.png`；无侧栏（顶栏导航）维持。
- 机制层**不重做**：虚拟化分层、SVG 渲染器、同帧机制、新鲜度三态、门禁与 e2e 全部沿用（PR #6 已合入）。本轮只动令牌与组件皮肤。
- 性能预算沿用（size-limit、离线单文件、SLO）+ 新增：镜面层纯 CSS 零脚本、本地 LCP < 1s、图表初始化 < 150ms、CLS = 0（守则细节 #5 既有）。

## 十、被弃备选

- **任意六色装饰系列**（无语义的好看）——被 D1 的语义色相取代；
- **3D 默认开**——遮挡与不可精确比较（tokscale 自家 Avoid 同判）；
- **大面积 backdrop-filter 玻璃**——合成开销与文字对比度风险，玻璃感由 1px 上缘 + 渐变承担；
- **行内多色分类**（每类一色）——守则既有禁令维持，色相只给图表系列；
- **Canvas 渲染器替换**——SVG 判决已由 spike 数据钉死（1096 点 ×3 系列满帧）；
- **排行榜默认开 / 明细上传**——隐私红线，仅聚合值 + opt-in。
