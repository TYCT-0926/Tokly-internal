# 首发主题规格

五套主题，每套 = 一个 ThemeFamily（id + defaultMode + dark/light 两个 VariantSeed，schema 见 令牌系统.md Tier 1；依据：二轮审查 §2 M1.5-1）。paper 为浅色优先（defaultMode="light"），其余 defaultMode="dark"。种子值即输入基准，实现时原样录入；派生规则与质量门见 令牌系统.md。

> oklch 括注为种子 hex 的实测换算值（2026-08-02 复核），仅供阅读；色彩合法性不设中间值域校验，**以派生后的最终对比度/gamut 质量门为唯一权威**（依据：二轮审查 §2 M1.5-3）。五套主题 × dark/light 共 10 个变体已按新规则全量核对：accent on canvas 3.85–13.17（≥3:1）、onAccent 4.85–14.35（≥4.5:1）、fg 各项均过门、heat ramp 8-bit roundtrip 最小相邻距离 ≈0.139（≥0.02），全部合法且无需救济（依据：二轮审查 §2 M1.5-6/7 复核）。

## 1. amber（签名默认）

气质：示波器与琥珀屏——暖近黑底上，数据读数像仪表一样发光。

```json
{
  "id": "amber",
  "defaultMode": "dark",
  "dark":  { "accent": "#E0985A", "bgBase": "#171310", "grayTint": 50 },
  "light": { "accent": "#B26A2E", "bgBase": "#FAF5EF", "grayTint": 50 }
}
```

- accent 实测 oklch：dark `0.739 0.117 60.2` / light `0.593 0.118 57.2`
- 琥珀色只用于：主按钮、焦点环、激活图表系列、热力图 ramp、状态栏签名行
- 成本/token 数字一律 fg.primary 中性色，不用琥珀——数字是仪表读数，不是霓虹

## 2. mono

气质：零色相。只有灰，唯一的"色"是明暗。最极端的反 AI 味，给极简主义者。

```json
{
  "id": "mono",
  "defaultMode": "dark",
  "dark":  { "accent": "#D4D4D4", "bgBase": "#101010", "grayTint": null },
  "light": { "accent": "#2A2A2A", "bgBase": "#FAFAFA", "grayTint": null }
}
```

- accent 实测 oklch：dark `0.870 0 0` / light `0.285 0 0`——**均落在已删除的旧 L∈[0.45,0.85] 值域之外，合法性的唯一权威是最终质量门**（实测 accent on canvas 12.93/13.17，依据：二轮审查 §2 M1.5-3）
- 热力图 ramp = 纯灰明度五档（C=0，跳过彩度缩放）；图表单系列 + 灰阶
- 状态色仍保留语义色相（令牌系统.md 状态色规则），否则成功/失败不可辨

## 3. slate

气质：保守专业，冷蓝灰。"普通好看"，给不想思考主题选择的人。

```json
{
  "id": "slate",
  "defaultMode": "dark",
  "dark":  { "accent": "#7AA2F7", "bgBase": "#0F1218", "grayTint": 262 },
  "light": { "accent": "#3B62C4", "bgBase": "#F6F8FB", "grayTint": 262 }
}
```

- accent 实测 oklch：dark `0.719 0.132 264.2` / light `0.522 0.159 265.0`

## 4. paper（浅色优先）

气质：报纸与账单。默认即浅色，深色为可选变体。

```json
{
  "id": "paper",
  "defaultMode": "light",
  "light": { "accent": "#A85F28", "bgBase": "#FFFFFF", "grayTint": 50 },
  "dark":  { "accent": "#D9964F", "bgBase": "#16130F", "grayTint": 50 }
}
```

- accent 实测 oklch：light `0.560 0.117 54.2` / dark `0.725 0.119 65.5`

## 5. sakura（表现力证明）

气质：主题系统表现力的上限测试——证明基座能承载"二次元类"主题且可读性自动达标。若它通过质量门，任何社区主题都能通过。

```json
{
  "id": "sakura",
  "defaultMode": "dark",
  "dark":  { "accent": "#F27BA7", "bgBase": "#16121A", "grayTint": 330,
             "overrides": { "bgImage": { "url": "演示占位（用户主题中真正的用法）" } } },
  "light": { "accent": "#C94F7E", "bgBase": "#FBF4F7", "grayTint": 330 }
}
```

- accent 实测 oklch：dark `0.730 0.153 358.2` / light `0.601 0.161 359.2`
- 作用：①验证 bgImage scrim 处理与运行时采样校验；②验证高彩度粉色下热力图 ramp 依然平滑；③社区主题的风向标
- 即使主题再"跳"，结构纪律（字号/间距/动效/对比度）与官方主题完全同级

## 主题管理规则

- 主题文件 = ThemeFamily JSON：官方主题内置，用户主题放 `~/.config/tokly/themes/<id>.json`（依据：二轮审查 §2 M1.5-1，用户主题同步改家族结构）
- 切换即时生效（CSS 变量全量替换 / TUI 重启视图），选择持久化，三端各自独立设置但共享同一主题文件源
- 校验失败（非法 JSON / 字段类型越界 / bgImage URL 协议不允许 / 派生质量门救济无解）：拒绝加载并回退默认主题，错误信息指到具体字段（依据：二轮审查 §2 M1.5-3/7/8——不再有中间值域校验，拒绝只发生在最终门禁无解时）
