# 编排规格（成页的设计——令牌与组件之上的第三层）

> 2026-08-04 新增（维护者方向确认）：令牌管色彩与字、组件规格管单体、**本规格管"组件如何编排成页"**——区带节奏、首载入场时序、屏间转场、数据到达的级联。消费方：阶段七B（Dashboard）、九（TUI 按其降级形态）、十（桌面窗口复用）。物理与感知纪律不变：只动 transform/opacity、时长取令牌三档、感知层三条（同时性 / 打断 / 方向对称，见[动效规格](动效规格.md)）全程适用。

## 一、区带节奏（页面骨架）

- 内容区 `content.max` 内按**区带（band）**组织：第一带（能力驱动：油表或 KPI）→ 第二带（趋势 + 热力图）→ 第三带（下钻表格）。
- 节奏数值：**带间 48px、带内组件间 24px、组件内 12/16px**——三级呼吸，禁止同级混用。
- **每屏一个主角**：视觉重心唯一（概览 = 第一带读数；下钻页 = 表格；设置 = 无主角全安静）。主角之外的带不得使用 accent 大面积着色。
- 分隔一律发丝线，不用底色块分区；带标题 = 13px fg.muted + 右侧延伸 hairline（与 TUI 面板标题同源语汇）。

## 二、首载入场编排（表现力主线 · 每会话仅一次）

| 时点 | 元素 | 动效 | 参数 |
|---|---|---|---|
| 0ms | 顶栏 + 状态条 | fade | 150ms ease-out |
| 80ms | 第一带（油表/KPI）逐项 | fade + translateY(4px→0) stagger | 每项 30ms，项动效 200ms |
| 240ms | 趋势图容器 | fade（图表本体入场动画恒关闭） | 200ms |
| 400ms | **热力图签名首播** | 按周列 stagger（动效规格既定） | 每列 8ms，封顶 500ms |
| ≤900ms | 编排结束 | 此后本会话一切即时 | — |

- 总时长硬上限 **900ms**；期间不阻塞交互（可点击即中断，直落终态——感知层打断规则）。
- `prefers-reduced-motion`：整条编排替换为单次 150ms 全屏淡入。
- 首次运行流程（组件规格 §10）的第 3 步"进入概览"即接本编排——导入摘要淡出、编排入场，一气呵成。

## 三、屏间转场

- 路由级优先 **View Transitions**（基线内渐进增强，[ADR-0009](../adr/0009-运行期基线.md)）：时间范围控件与页标题作共享元素，位置连续；不可用时回落 WAAPI 全页 crossfade 150ms。
- 下钻/返回沿用动效规格的方向对称（生长 200 / 逆向收回 120）；转场期间禁用元素级动画（避免同时性超限）。
- 设置页进出 = 纯 crossfade（无空间语义，不做位移）。

## 四、数据到达的级联

- SSE 更新遵守"用户动效优先"（动效规格感知层 1）；系统更新多块同时到达时**按带序 60ms 级联**（第一带 → 图表 → 表格），每块 150ms crossfade——避免全屏同帧齐闪；超过 3 块合并为同帧（级联过长比齐闪更吵）。
- 单数字变化仍禁滚动计数（既定）。

## 五、每屏动效预算表

| 屏 | 允许 | 禁止 |
|---|---|---|
| 概览 | 首载编排（仅一次）+ 签名首播 + 级联更新 + 微交互 | 重复入场、装饰性循环动画 |
| 下钻页 | 转场 + 行级展开/收回 + 微交互 | 表格行 stagger 入场 |
| 设置 / 数据健康 | 仅微交互（hover/focus/切换） | 一切入场编排 |
| 首次运行 | 进度本身即动效（计数滚动**允许**——此处数字是过程不是读数）+ 摘要→概览衔接 | 额外装饰 |

## 六、验收（并入七B 设计验收，机器可判项进 Playwright）

- [ ] 首载编排逐帧时序与表内时点误差 ≤1 帧；总长 ≤900ms；期间点击即中断直落
- [ ] reduced-motion 下编排完全替换为单次淡入
- [ ] 级联更新无同帧齐闪（逐帧断言带序）
- [ ] 区带节奏三级数值零违例（Stylelint 间距白名单）
- [ ] 每屏预算表逐项自查；新增任何编排级动效须先改本表
