# ADR-0017: 令牌派生引擎的归属与用户主题

- 状态：accepted
- 日期：2026-08-03

## 背景

[ADR-0005](0005-主题架构.md) 把派生引擎定为**构建期**的 culori（JS），产出 CSS 变量、Rust 常量、TUI 主题三份产物，运行期零计算。同一份 ADR 又开放 Tier 1 让用户自定义主题，[令牌系统](../design/令牌系统.md)规定用户主题放 `~/.config/tokly/themes/<id>.json` 运行时加载并校验。

**这两条不能同时成立。** 用户主题的 Tier 2 令牌需要跑完整的 OKLCH 派生、gamut 映射、对比度救济算法，而该算法只存在于构建期的 JS 实现里；产品又不含任何 JS 运行时（[ADR-0001](0001-技术栈与运行时.md) 硬约束）。[路线图](../路线图.md) M1.5 只列了"构建期三产物生成器"，这笔账没有承载方。

可选路径只有四条，其中两条一眼即否：

| 路径 | 判决 |
|---|---|
| 用户主题在浏览器里用 JS 派生 | 否。TUI 与桌面窗口拿不到，且违反"运行期零计算"，golden 一致性无法验证 |
| Rust 与 JS 各实现一遍 | 否。两份实现必须与 golden 快照逐字节一致，这是一个永不结束的正确性负担 |
| 砍掉用户自定义主题 | 见下 |
| 派生引擎迁到 Rust | 见下 |

真正的取舍只在后两者之间。

## 决策

### 派生引擎的唯一实现是 Rust

新建 `crates/tokly-tokens`：DTCG 源解析、OKLCH 派生、gamut 映射、对比度救济、质量门、ANSI 降级链，全部在 Rust 内（色彩运算用 `palette` crate，gamut 二分与救济是其上约百行的自有逻辑）。**culori 与 JS 派生实现退出。**

- **构建期**：`cargo xtask tokens` 调用它生成三份产物，产物形态与消费方式不变；
- **安装期**：`tokly theme install <path>` 调用同一份代码派生用户主题，产出写入 `<data_dir>/tokly/themes/<id>.css` 与 TUI 主题 JSON；daemon 经 HTTP 提供 CSS，桌面窗口同源消费。

"运行期零计算"依然成立——**运行期消费的仍然只是 sRGB 字面量**，只是这些字面量的生成时机从"发版时"扩展到"用户安装主题时"，而生成器是同一个。

`packages/design-tokens` 从"派生引擎"降级为"DTCG 令牌源加 preview 验证页"，不含算法。

### 主题校验的失败面收敛到一处

`tokly theme install` 是唯一入口，校验在此一次性完成：JSON 结构 → 字段类型 → 色彩可解析 → 派生 → 质量门。任一步失败拒绝安装并指到具体字段，**不产出半成品**。

运行时因此不再需要"加载失败回退默认主题"的分支——**装进去的主题必然已经过质量门**。这是一处净减法：把一个运行期的错误路径变成了安装期的一次性校验。

## 为什么现在做

M1.5 是设计基座验证里程碑，它的交付物就是这个引擎。现在定，成本是选一个 Rust 色彩库；等到 M1.5 按原计划用 culori 做完、M5 桌面端要支持用户主题时才发现，成本是把已经写完并冻结了 10 份 golden 快照的引擎整体重写，且期间要维持两套口径——与 ADR-0001 拒绝"先 TS 后迁 Rust"的理由完全同构。

## 代价与备选

- **备选：砍掉用户自定义主题，只留五套官方主题。** 这是真实可选项，代价是 ADR-0005 明确列为核心收益的两条——"用户主题不可能产出丑结果""主题市场与分享是安全的远期功能"——以及公开仓设计原则里已经预留的 `tokly theme install`。弃选理由：主题表现力是这个产品少数几个能形成情感连接与自发传播的面（`sakura` 主题存在的全部意义就是证明这一点），而保留它的代价只是把一段算法写在 Rust 而非 JS 里——这个交换明显划算。
- **代价**：放弃 culori 的成熟度。OKLCH 转换与 gamut 判定在 `palette` 中有对应能力，自有逻辑集中在二分降彩度与对比度救济两处，均已在[令牌系统](../design/令牌系统.md)中写成可编码的算法。风险由 10 个官方变体的 golden 快照守住。
- **代价**：Rust 侧的色彩数值必须与文档中的参考输出对齐一次。这是一次性成本，且本来就要做——令牌系统已经声明"最终输出以实现提交时冻结的 golden 快照为唯一权威"。
- **附带收益（不是决策理由，但值得记）**：TUI 的 ANSI 降级链需要 OKLab 距离计算，原本也在 JS 管线里。归一到 Rust 后，三端的色彩结论出自同一次计算，一致性不再依赖人工对齐。

## 后果

- ADR-0005 的「OKLCH 派生引擎（culori）在构建期运行」被本 ADR 取代。三层令牌、开放边界、首发五主题、签名元素全部不变。
- [路线图](../路线图.md) M1.5 交付物改为 `crates/tokly-tokens` + `packages/design-tokens`（源与 preview）+ `tokly theme install`。
- 新增 CLI 子命令 `tokly theme install|list|remove`。
- [令牌系统](../design/令牌系统.md)的"导出格式"节改为引用本 ADR 描述生成时机。
