# ADR-0007: 国际化（i18n）

- 状态：accepted（2026-08-02 三轮终审：自研 `t()` 改为 Fluent，.ftl 为唯一消息源）
- 日期：2026-08-02

## 背景

产品面向全球开发者（开源），用户首要语言为中文。界面需要中英双语且"正确地多语言"——不是后期打补丁。

## 决策

### 语言

首发 **zh-CN + en**，跟随系统语言自动选择，设置中可手动覆盖，选择持久化。语言包缺失时回退 en。

### 实现原则

- **第一天就 i18n**：任何界面文案不得硬编码，全部走消息 key
- **实现方案（2026-08-02 三轮终审，推翻自研 `t()` + lint 禁裸字符串）**：**Fluent——`.ftl` 文件为唯一消息源**。Web 侧 `@fluent/react`，Rust 侧 `fluent-bundle`，两端读同一份 .ftl；构建期生成 typed key（TS / Rust 双侧），引用不存在的 key 编译期即红。CI 校验四项：**缺 key / 死 key / 变量不匹配 / 伪本地化**（pseudo-locale 渲染冒烟）。弃自研 `t()` 的理由：自研函数解决不了复数 / 性别 / 变体的语法正确性（Fluent selector 是标准答案），且 .ftl 对翻译贡献者友好
- 语言包按命名空间组织（`common` / `dashboard` / `settings` / `sources`），zh-CN 与 en 的 .ftl 文件结构镜像（key 对齐由上述 CI 校验保证）
- **数字与格式本地化**：日期、千分位走 `Intl` API（zh-CN `1,234` 与 en 一致但日期格式不同）；**数字读数的 tabular-nums 与紧凑记数规则与语言无关**（`3.4M` / `$12.80` 全语言统一格式）
- 技术名词不译：token、cache、session、模型名等保持英文原形（双语共同约定，写进语言包规范）
- TUI 与 Web 共享同一份 .ftl 消息源（core 经 fluent-bundle、Web 经 @fluent/react 各自消费），桌面随 Web

### 不做

- 不做 RTL；不预置更多语言（社区贡献通道留在公开仓 CONTRIBUTING）
- 文档不双语，docs 维持中文为主——**README 例外（2026-08-02 审查 §三 P2-15）**：README 以英文为主 + 末尾中文简介段。英文 README 是全球开发者的转化墙（star/采用决策的第一触点），转化率优先级高于文档一致性；docs 深入内容仍以中文为主，不做全量双语维护。

## 后果

- i18n 独立成包（.ftl 消息源 + typed key 构建期生成器），Rust core 与 Web 共享。
- PR 检查清单增加：文案改动需双语同步（已写入公开仓 CONTRIBUTING）。
