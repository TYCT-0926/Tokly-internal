# ADR-0016: i18n 的运行期归属与格式化

- 状态：accepted
- 日期：2026-08-03

## 背景

[ADR-0007](0007-国际化.md) 定了 Fluent 与 `.ftl` 单一消息源，但留了两个直接影响 DTO 契约与 TUI 质量的空白：

1. **谁做本地化**：[架构总览](../架构总览.md)把 `fluent-bundle` 放在 `tokly-service`，ADR-0007 又说 Web 侧走 `@fluent/react`。服务端返回已本地化字符串与返回 key 加参数，是两种完全不同的 DTO——而 DTO 由 ts-rs 生成、前端禁止手抄，改起来牵动两侧。
2. **Rust 侧的数字与日期格式化没有方案**：ADR-0007 写"走 `Intl` API"，而 `Intl` 是 JS-only。`tokly report` 与 TUI 打印的千分位、紧凑记数、日期全无着落。

## 决策

### 服务端不做本地化

`tokly-service` 与全部 DTO 只返回**结构化数据加消息 key 与参数**，永不返回面向人的成品字符串。渲染发生在展示端：Web 用 `@fluent/react`，TUI 与 CLI 用 `fluent-bundle`。

理由是形态本身要求的：同一个 daemon 可能同时服务一个中文桌面窗口和一个英文浏览器标签页。把语言固化进 DTO，语言切换就需要往返服务端一次。

### Rust 侧格式化：自建两 locale 规则，不引 ICU

首发只有 zh-CN 与 en，实际差异面很小：

| 项 | zh-CN | en |
|---|---|---|
| 千分位分组 | `1,234` | `1,234`（相同） |
| 紧凑记数 | `3.4M` | `3.4M`（[ADR-0007](0007-国际化.md) 已定与语言无关） |
| 货币 | `$12.80` | `$12.80`（相同） |
| 日期 | `2026/08/03` | `Aug 3, 2026` |
| 时间 | 24 小时制 | 24 小时制（开发者工具惯例，不用 AM/PM） |

由 `tokly-format` 模块承担，规则表显式列出。**与 Web 侧 `Intl` 的一致性靠共享测试向量保证**：一份 `(locale, 值, 期望输出)` 的 fixture，Rust 与 TypeScript 两侧必须同时通过——一致性由测试强制，不靠人工对齐。

### Fluent 双向隔离符在终端关闭

Fluent 默认在插值处插入双向隔离符（FSI / PDI）。这些不可见控制字符会破坏 TUI 的列对齐，而[组件规格](../design/组件规格.md)有"数字右对齐""80 列不崩"的硬要求。

**TUI 与 CLI 的 bundle 一律 `set_use_isolating(false)`，Web 侧保持默认。** 首发两语言均为 LTR，关闭无副作用。

## 为什么现在做

DTO 是否含成品字符串是契约级决策：它决定生成的 TS 类型形状，也决定服务层是否依赖 `fluent-bundle`。M2 之后再改，要动的是全部端点与全部前端消费点。

Fluent 隔离符这一条现在写只需一行，等到 M4 做 TUI 时才发现，症状是"列偶尔错一格"——这类问题极难定位，因为字符不可见。

## 代价与备选

- **备选一：Rust 侧引 ICU4X 与 `Intl` 同源 CLDR。** 弃选理由：为两个 locale、五项格式引入一个带数据包的依赖，会给 CLI 二进制增加 MB 量级体积，直接顶到"CLI 启动 < 100ms"与轻量分发这两条硬指标上。**社区新增语言时重新评估**——那时收益才成立。
- **代价**：自建格式化意味着两侧实现可能漂移。共享测试向量把这个风险变成一个会红的测试，而不是一个会被发现的 bug；代价是每加一条格式规则要同时加向量。
- **备选二：服务端本地化，DTO 直出成品字符串。** 弃选理由：多端多语言并存时需要往返；且会让 service 层依赖展示层的关注点，与"transport 无关"的边界冲突。
- **代价**：展示端各自渲染意味着 TUI 与 Web 各有一套渲染代码。这是可接受的——它们的输出介质本来就不同（braille 与 DOM），共用的只应该是消息源与格式规则。

## 后果

- DTO 契约增加一条硬约束：**任何 DTO 字段不得含面向人的成品字符串**，由生成的类型与 review 共同保证。
- `tokly-service` 不再依赖 `fluent-bundle`，依赖下移到 `tokly-tui` 与 `tokly-cli`；[架构总览](../架构总览.md)包职责表按此修订。
- 新增 `tokly-format` 模块与跨语言格式测试向量，进 M1（`tokly report` 需要它）。
