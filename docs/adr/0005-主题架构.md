# ADR-0005: 主题与设计令牌架构

- 状态：accepted（2026-08-02 三轮终审：导出器改为 DTCG 源 + 构建期三产物。**2026-08-03 四轮**：派生引擎的语言与运行时机被 [ADR-0017](0017-令牌派生引擎.md) 取代——旧的「culori 构建期」与本 ADR 开放的用户自定义主题不能同时成立。三层令牌、开放边界、首发五主题、签名元素全部不变）
- 日期：2026-08-02

## 背景

产品要求顶级视觉、多主题、用户可自定义，同时杜绝"AI 味"。风险：开放的自定义会让用户产出低质量配色，损害产品质量；多主题若逐个人工调谐则维护成本爆炸。

## 决策

### 三层令牌（design tokens）

- **Tier 1 · 原语**：主题家族种子 **ThemeFamily**（`{id, defaultMode, dark: VariantSeed, light: VariantSeed}`；VariantSeed = OKLCH 色彩种子：强调色、底色温、灰阶倾向）、字号阶梯、间距网格、动效时长/曲线。主题作者与用户自定义**只能触达这一层**。（2026-08-02 二轮审查 §2 M1.5-1：ThemeSeed 升级为 ThemeFamily，深浅变体成对收录。）
- **Tier 2 · 语义**：`bg.canvas / bg.raised / fg.primary / fg.muted / border.hairline / accent.solid / state.* / shadow.overlay / chart.series.* / heat.0..4 / status.*`。由 Tier 1 **程序化派生**——色彩 ramp 用 OKLCH 插值生成，任何种子输入都产出感知均匀的渐变。派生引擎必须 **gamut-aware**：全部派生色统一"保持 L/H、二分降 C 至 linear-sRGB 合法（容差 1e-6）"，heat ramp 另按各档可显示彩度上限**统一缩放**（不逐点 clamp）；**不设种子中间值域校验**（旧 L∈[0.45,0.85] 硬边界已删除，mono 官方种子自身越界），色彩质量以派生后的最终对比度/gamut 质量门为唯一权威，救济无解才拒绝种子（2026-08-02 二轮审查 §2 M1.5-3/5/7 修正，OKLCH 数值实证）。具体数值与算法见 [design/令牌系统.md](../design/令牌系统.md)（gamut 映射、对比度救济、heat 双模式 ramp、8-bit roundtrip 检查、完整 token manifest）。
- **Tier 3 · 组件**：KPI 读数、表格行、热力图单元格等组件级映射，由 Tier 2 组合，不直接引种子。

自定义边界：Tier 1 开放（种子 + 白名单覆盖项），Tier 2/3 派生只读，布局/字号/间距/动效不开放。任何用户主题自动继承全部设计纪律（对比度、ramp 平滑、动效统一）。

### 一份令牌，构建期三份产物（2026-08-02 三轮终审修订）

令牌源为 **DTCG 格式 JSON**（W3C Design Tokens 社区格式）单一定义源；OKLCH 派生引擎生成三份产物，运行期零计算。

> **2026-08-03 修订**：引擎的语言与运行时机改由 [ADR-0017](0017-令牌派生引擎.md) 定——唯一实现在 Rust（`crates/tokly-tokens`），构建期由 `cargo xtask tokens` 调用、安装期由 `tokly theme install` 调用同一份代码。culori 退出。产物形态与"运行期只消费 sRGB 字面量"不变。

1. **CSS variables** → Web Dashboard 与桌面窗口（Tauri 复用同一份）；
2. **Rust 常量**（codegen）→ core / TUI 直接引用，令牌值变更编译期可见，杜绝「Web 改了 TUI 没改」；
3. **TUI 主题**（Ratatui 主题结构）→ 含 truecolor → 256 色 → 16 色的降级链（OKLab 欧氏距离最近匹配、同距取最低 index、ANSI16 固定语义映射表，规则见 [design/令牌系统.md](../design/令牌系统.md) ANSI 降级节——降级链规则不变）。

主题注册表（设置界面枚举、用户主题校验）由构建期产物加已安装用户主题共同承载；用户主题的全部校验在 `tokly theme install` 一次性完成，运行时不再有"加载失败回退默认"的分支（[ADR-0017](0017-令牌派生引擎.md)）。

### 首发主题（五套，深浅成对）

`amber`（签名默认）/ `mono`（零色相纯中性）/ `slate`（冷蓝灰）/ `paper`（浅色优先）/ `sakura`（表现力证明）。（2026-08-02 二轮审查 §2 M1.5-2：统一为五套，与 [design/主题.md](../design/主题.md) 一致；原文漏列 sakura。）主题文件 = ThemeFamily（Tier 1 种子 + 白名单覆盖项），ramp 全部派生。

### 签名元素

**热力图是 Tokly 的品牌对象**，三端同源渲染：Web CSS Grid / TUI braille / 桌面 Widget 迷你版。单色相 OKLCH 明度 ramp、中性空格、按用户自身峰值相对标定、悬停精确值。该组件享有最高设计优先级与独立的视觉验收标准。

## 后果

- 新增官方主题 = 写一个种子文件（约 30 行），无需重新设计。
- 用户主题不可能产出丑结果（结构性纪律不可触达），主题市场/分享是安全的远期功能。
- 三端视觉一致性由单一令牌源 + 构建期产物保证，不靠人工对齐；运行期（含 WebKit 系桌面窗口）只消费 sRGB 字面量，不依赖 OKLCH 运行时支持（[风险登记](../风险登记.md) R7）。
