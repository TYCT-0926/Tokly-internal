# ADR-0001: Monorepo 形态与运行时选型

- 状态：accepted（2026-08-02 **三轮终审定稿**：内核从「全 TypeScript + Bun」切换为「Rust 内核 + TypeScript 界面」；Web 层 React 19 不变。**2026-08-03 四轮修订**：清除换栈残骸并补齐未决项——ECharts 渲染器、动效实现路径、DTO 生成器、令牌引擎、发布工具五处定稿，依据 [ADR-0009](0009-运行期基线.md) / [ADR-0013](0013-分发信任链.md) / [ADR-0017](0017-令牌派生引擎.md) 与 [审查-2026-08-03](../research/审查-2026-08-03.md)。内核方向不变。被推翻的前决策见末节两份清单）
- 日期：2026-08-02

## 背景

Tokly 需要三端（Web / TUI / 桌面）共享同一份数据采集与存储逻辑。核心工作是解析各家格式各异的本地日志并归一化。硬性要求：极致性能与轻量安装、顶级视觉、单一代码库。

三轮终审推翻前两轮的「全栈 TypeScript」前提，论据：

- **「单语言」是幻觉**：桌面端锁定 Tauri（安装包 2.5–10MB vs Electron 85–244MB，前两轮已决策且不变），Tauri 强制 Rust 工具链——双语言本就不可避免，问题只是 Rust 放在哪一层、占多大。
- **市场收敛证据（2026-08-02 时点）**：同赛道头部向 Rust/原生迁移——ccusage 之后 tokscale 用 Rust 重写核心，CCSeva 弃 Electron 重写为 Swift 原生（3MB），CodexBar 走原生壳。「本地日志解析 + 聚合」负载上 Rust 是该品类的收敛答案（[竞品调研](../research/竞品调研.md)）。
- **Bun 风险随栈切换关闭**：OpenTUI 在 Windows 的四层故障源（Bun → JS reconciler → OpenTUI → 原生 DLL）、node:sqlite 缺失、94MB 编译体积地板、sidecar 孤儿进程（原风险登记 R1），全部随被移除的技术层消失，无需再为它们维护逃生通道。
- **口径不变量编译期强制**：收敛契约（[ADR-0002](0002-数据架构.md)：事件身份 / 可比 revision 域 / 显式冲突 / 事务边界）在 Rust 类型系统下可成为编译期不变量；proptest + insta 是收敛契约 property tests 与 golden fixtures 的最强生态。
- **UI/UX 维度与内核语言无关**：Web 前端仍是 React，设计令牌 / 组件规格 / 动效规格零改动——换栈的美观成本为零。
- **「先 TS 后迁 Rust」被明示否决**：零代码时切换成本为零；M3 之后迁移等于整体重写 core/adapter/pricing 三层，且迁移期要维持两套口径。

## 决策（分层栈，2026-08-02 三轮终审）

| 层 | 选型 | 要点 |
|---|---|---|
| 产品内核 | **Rust** | adapter 一源一 crate（serde 流式解析）；归一化 / 收敛 / 计价 / 聚合全在 core |
| SQLite | **rusqlite（bundled，全表 STRICT）** | 写连接唯一且串行、读走连接池，全部经 `spawn_blocking`（[ADR-0012](0012-进程与本地服务.md)）；PRAGMA 固化集合见 [数据库-schema](../数据库-schema.md)。**`cache_size=-16000` 的 4–5 倍提升实测出自 Bun + bun:sqlite 栈，「与驱动无关」无证据支撑，须在 M0.5 spike ① 上按 rusqlite 重测并重新打戳** |
| 本地服务 | **Tokio + Axum + SSE** | 仅 127.0.0.1；随机 token + `Origin`/`Host` 校验，token 经 URL fragment 传递（[ADR-0012](0012-进程与本地服务.md)） |
| Web UI | **TS strict + React 19 + React Compiler** | 交互原语 **React Aria Components**（日期范围 / 虚拟表格 / 焦点恢复 / 读屏测试面更强；不混用两套 focus 系统）；React Compiler 消除 memo 纪律负担 |
| 样式 | CSS Modules + 令牌变量 + Cascade Layers + **Lightning CSS** | **Stylelint 强制令牌纪律**；不用 Tailwind（原子类绕过令牌纪律，默认观感是可识别模板） |
| 图表 | **模块化 ECharts 6 懒加载**（~197KB gzip） | 买到的是 dataZoom / Universal Transition / 成熟 tooltip 与 axisPointer。**「ARIA 完整面」这条理由删除**——图表的文本摘要与表格等价物无论如何要手写（设计原则硬要求），留着它会变成跳过无障碍工作的借口。**渲染器在 M0.5 spike ② 定格**：首选 SVG（主题切换可随 CSS 变量同帧），实测 dataZoom 不达标则回退 canvas + 主题切换过渡编排。热力图 CSS Grid + sparkline 手写 SVG 不变 |
| 动效 | **CSS transitions + WAAPI，无 JS 动画库** | 弹簧改为构建期生成的 `linear()` 缓动令牌、浮层用 `@starting-style`、下钻优先 View Transitions——**Motion for React 移除**（[ADR-0009](0009-运行期基线.md) 抬高运行期基线后它不再有不可替代能力）。参数与感知层纪律见 [design/动效规格.md](../design/动效规格.md) |
| TUI | **Ratatui + Crossterm** | 与 core 同进程（无 IPC 层）；Crossterm 的 Windows 路径成熟（ConPTY 一等支持）；TestBackend 快照测试 |
| 桌面 | **Tauri 2 直嵌 Rust core** | 无 Bun sidecar、无 Node、无独立进程；React 经 Tauri IPC/events，浏览器经 Axum——两 transport 薄适配（[ADR-0004](0004-桌面端分发.md)）。弃选 Electron（体积）与 Neutralino（生态过弱）不变 |
| 字体 | 自托管 Geist Sans + Maple Mono | 打包进产物，不走 CDN（本地优先一致性），不变 |
| 设计令牌 | **DTCG JSON + OKLCH；派生引擎在 Rust（`palette`）** | 同一引擎服务构建期三产物与 `tokly theme install` 的用户主题派生，culori 退出（[ADR-0017](0017-令牌派生引擎.md)） |
| i18n | **Fluent（.ftl 唯一消息源）** | 渲染在展示端，**service 与 DTO 不返回成品字符串**；Rust 侧数字与日期自建两 locale 规则，不引 ICU（[ADR-0016](0016-i18n运行期.md)） |
| DTO 契约 | **ts-rs**（2026-08-03 定稿，不再与 typeshare 并列） | derive 宏与 serde 属性同源、无独立解析步骤、导出经测试进 CI；**前端禁止手抄领域模型** |
| Monorepo | **Cargo workspace + pnpm workspace + cargo xtask** | xtask 为统一任务入口（构建 / 测试 / 生成 / 发布）；无 Turborepo |
| 测试 | nextest / proptest / insta / criterion + Vitest / RTL / axe / Playwright | proptest 验收敛契约四场景；insta 管 golden fixtures；criterion 守性能 SLO |
| 分发 | **cargo-dist + Tauri 安装包 + npm 原生二进制启动器；版本走 release-plz** | 保住 `npx tokly` 通路；Node/pnpm 只用于构建，**不随产品分发**。签名、公证、更新与版本工具见 [ADR-0013](0013-分发信任链.md)（changesets 已弃） |

## 被推翻的前决策（2026-08-02 三轮终审）

- **全栈 TypeScript（core 为 TS 库，三端复用类型）** → Rust core；TS 退到 Web UI 一层，跨语言类型只许 ts-rs/typeshare 生成，不手抄。
- **Bun 产品运行时**（`bun build --compile` 单文件、bun:sqlite/node:sqlite 双驱动适配、「core 在 Node 24+ 无损运行」硬约束）→ 产品无 JS 运行时，Node/pnpm 仅构建期存在。原 Bun 单点风险关闭（[风险登记](../风险登记.md) R1）。
- **OpenTUI（@opentui/solid）** → Ratatui + Crossterm：砍掉 Bun / JS reconciler / 原生 DLL 三层故障源；与 core 同进程零 IPC；Windows 质量不再依赖 OpenTUI 上游进度。
- **Radix UI** → React Aria Components：日期范围 / 虚拟表格 / 焦点恢复 / 读屏测试面更强；动效规格早已按 React Aria 写，本决策使其一致。
- **uPlot** → 模块化 ECharts 6：uPlot 的体积优势（~45KB）在懒加载下不构成取舍，ECharts 用 ~197KB gzip 买到交互 / 缩放 / Universal Transition / ARIA 完整面。
- **桌面 sidecar 分发**（v1 内嵌 Bun sidecar / v2 托盘 Rust 直读 / M5 决策门）→ Tauri 直嵌 core 提前定案（ADR-0004）。
- **自研 `t()` i18n** → Fluent（ADR-0007）。
- **pnpm workspaces + Turborepo** → Cargo workspace + pnpm workspace + cargo xtask。
- **「性能靠架构而非 Rust 原始速度，tokscale 路线不跟」**（前轮取舍）→ 终审反转：市场证据与 Bun 风险使 Rust 本身成为答案，架构结论（水位线增量摄取）不受影响。

## 前端数据与导航层（2026-08-03 追补——四轮审查后发现的三处未决）

决策表覆盖了框架、组件、样式、图表、动效，但 SPA 还有三层从未决策：服务端状态怎么拿、导航状态放哪、长列表怎么虚拟化。三者都影响 M0.5 spike ② 的构建，现补齐：

| 层 | 选型 | 理由与边界 |
|---|---|---|
| 服务端状态 | **TanStack Query** | 数据流是「查询 + SSE 增量推送」：SSE 事件到达 → 按 key 失效 → 重取。请求去重、窗口聚焦重取、失效语义是成熟轮子（~12KB），自建 fetch + effect + 手写失效只会长成一个劣质复刻。本地 < 100ms 的查询不减少对**失效语义**的需求，只减少对 loading 态的需求 |
| 客户端状态 | **不引全局状态库** | 主题/语言/时区在配置面（ADR-0010），服务端数据在 Query，剩下的只有组件级 UI 瞬态——React state 足够。Redux/Zustand/Jotai 均无需求支撑，引入即违反简单优先 |
| 路由与 URL | **TanStack Router；「URL 即状态」为硬规则** | 时间范围、下钻路径（源/模型/项目/会话）、选中维度**全部编码进 URL**——可分享、可后退、刷新不丢，这是仪器感的一部分（状态可复现）。选 TanStack Router 因其类型安全的 search params 校验与「DTO 只许生成不许手抄」同构：路由参数错误编译期即红。备选 React Router v7 弃于 search params 无类型 |
| 虚拟滚动 | **React Aria Virtualizer 优先** | 与 React Aria Table 的焦点/读屏语义原生集成；不足时回退 TanStack Virtual。在 spike ② 用 10 万行数据实测定格 |
| code splitting | 路由级分包 + ECharts 按需注册 + 非首屏组件懒加载 | 首屏预算 < 300ms 的实现路径；ECharts ~197KB gzip 永不进首包 |

## 被推翻的前决策（2026-08-03 四轮修订）

五条全部属于换栈残骸或未决项，不涉及内核方向：

- **Motion for React**（签名时刻专用的 JS 动画库）→ 平台原生。依据是 [ADR-0009](0009-运行期基线.md) 抬高的运行期基线：Motion 唯一不可替代的能力是弹簧曲线，而 `linear()` 缓动可在构建期把弹簧编码成令牌。
- **culori 构建期派生引擎** → Rust `tokly-tokens`。旧方案与"用户可自定义主题"不能同时成立（产品无 JS 运行时），[ADR-0017](0017-令牌派生引擎.md) 给出取舍分析。
- **changesets** → release-plz（[ADR-0013](0013-分发信任链.md)）：changesets 是 npm 包版本工具，与 Cargo workspace 错配，属全栈 TypeScript 时代遗留。
- **`ts-rs / typeshare` 并列** → ts-rs 定稿：DTO 生成器是契约级工具，不允许留两个候选。
- **ECharts 的「ARIA 完整面」选型理由** → 删除。选型本身不变，但该理由不成立。

同批清除的事实性残留：架构总览的 `fsnotify`（Go 库名，Rust 应为 `notify` crate）。

## 代价与封顶

- **adapter 迭代速度下降**（Rust 开发速度低于 TS）→ 封顶：adapter 模板 + 测试 harness（golden fixtures 脚手架）；M6 贡献套件把单 adapter 成本压到「写映射 + 喂 fixture」（[路线图](../路线图.md) M6）。
- **双语言维护面** → 封顶：cargo xtask 统一入口，贡献者只记一套命令；CI 用 sccache + nextest 控制时长；DTO 只许生成不许手抄，杜绝双语言口径漂移。
- **贡献门槛升高**（Rust 贡献者池小于 TS）→ 封顶：M6 贡献套件（spec 模板 / fixtures 脚手架 / 能力声明 checklist）；Web 层仍是 TS，UI 贡献不受阻。

## 后果

- 目录结构：`crates/`（core、adapter-*、pricing、service、cli、tui 等）+ `apps/web` + `apps/desktop`（Tauri 壳）+ `packages/`（design-tokens 构建器、i18n typed key 生成等构建期 TS）。
- CI 需要 Rust（stable，三平台矩阵）+ Node/pnpm（仅 Web 构建与发布）两条工具链。
- 同步修订（2026-08-02 三轮终审）：[ADR-0004](0004-桌面端分发.md)、[ADR-0005](0005-主题架构.md)、[ADR-0006](0006-开源发布.md)、[ADR-0007](0007-国际化.md)、[架构总览](../架构总览.md)、[路线图](../路线图.md)、[风险登记](../风险登记.md) R1 关闭并新增 R6/R7。
