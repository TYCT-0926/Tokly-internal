# ADR-0006: 开源策略与发布分发

- 状态：accepted（2026-08-02 三轮终审：分发随栈切换改为 cargo-dist + npm 原生二进制启动器。**2026-08-03 四轮**：「版本管理」整节被 [ADR-0013](0013-分发信任链.md) 取代——changesets 与 Cargo workspace 错配，且原文漏了签名、公证与更新通道这三件会直接卡住分发的事。许可证与渠道决策不变）
- 日期：2026-08-02

## 背景

Tokly 是开源项目，托管 GitHub。需要确定许可证、发布渠道、版本管理。

## 决策

### 许可证

**MIT**。理由：同类工具的事实标准（ccusage/tokscale 均为 MIT）；本项目目标是最大化采用，无商业保护诉求；依赖侧许可证兼容。

> 2026-08-03：原文举的 culori 已随 [ADR-0017](0017-令牌派生引擎.md) 退出依赖。更要紧的是"全部 MIT 兼容"此前只是断言——现由 CI 的 `cargo-deny licenses` 强制（[风险登记](../风险登记.md) R9）。

### 发布渠道（双轨；2026-08-02 三轮终审修订）

1. **npm**：`tokly` 为**原生二进制启动器包**——按平台分发 cargo-dist 产出的预编译二进制，安装器按 `process.platform/arch` 选二进制，`npx tokly` 通路保留（ccusage 已验证该通路是开发者主入口）。npm 包只含启动器与平台二进制，**不含需 Node 运行的 JS 核心**（产品无 JS 运行时，ADR-0001）。
2. **GitHub Releases**：桌面安装包（Tauri，三平台，~10MB 级）+ CLI 原生二进制（cargo-dist，三平台单文件，零运行时依赖——原 `bun build --compile` ~100MB 单文件方案随栈切换废止）。

### 版本管理 —— 已被 [ADR-0013](0013-分发信任链.md) 取代（2026-08-03）

原文三条的处置：

- ~~changesets~~ → **release-plz**：changesets 是 npm 包版本工具，本产品是 Cargo workspace 加一个二进制启动器包，属全栈 TypeScript 时代的遗留。
- ~~1.0 在 M3 Dashboard 稳定后~~ → **1.0 门与[路线图](../路线图.md) M2 对齐**：原文与路线图（Dashboard 在 M2）自相矛盾。
- 发布流水线补入签名与公证、更新清单签名两步——未签名的桌面产物在 macOS 与 Windows 上是装不上而非不好看。

语义化版本与 0.x 阶段允许破坏性变更不变。

### 社区文件

`LICENSE`（MIT）、`SECURITY.md`（含隐私立场）、`.github/`（issue 模板、PR 模板、CI）、`CONTRIBUTING.md`——均在公开仓。

## 后果

- 仅 CLI 启动器包发布 npm；crates 不发布 crates.io（产品是应用而非库）；web 构建产物随 CLI/桌面渠道分发。
- CI 需要 npm token 与 GitHub Release 权限（仓库 secrets 配置）。
