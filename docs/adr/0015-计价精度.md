# ADR-0015: 计价的数值精度与舍入

- 状态：accepted
- 日期：2026-08-03

## 背景

[数据库-schema](../数据库-schema.md) 把金额定为 `INTEGER` micro-USD 以避免 REAL 聚合漂移，价格表存 `unit_price_micro_usd` 加 `per_unit`。但计价公式 `tokens × unit_price / per_unit` 是整数除法，而**舍入策略从未定义**：

- 两次 reprice、两个实现、两种求和顺序都可能给出不同结果——而决定论是这个项目的核心不变量，收敛契约的四个 property test 全部建立在"终态逐字节一致"之上，计价却在这个不变量之外；
- 低单价档（cache read 量级 $0.03/1M）在小 token 数上直接截断为 0，损失系统性向下偏。

另有一个结构性缺口：[风险登记](../风险登记.md) R2 的对冲是"按事件时点匹配 `pricing_history`"，但**首次安装之前的历史事件根本没有价目历史**——远程价目无历史维度，本地覆盖层从首次抓取才开始。存量历史只能按首次抓取价计算，而这正是 R2 警告的那种"用今天的价回算历史"。

## 决策

### 计算与舍入

```
cost_micro = round_half_even(
    Σ_kind ( tokens_kind × unit_price_micro_kind / per_unit_kind )   // i128，不逐档舍入
)
```

三条规则：

1. **中间计算用 i128，逐 price_kind 精确累加后一次性舍入**——不是逐档舍入再求和，避免累积偏差；
2. 舍入模式 **round-half-even**（银行家舍入），无方向性偏置，长期期望误差为零；
3. 求和顺序固定为 price_kind 的**字典序**，保证结果与遍历顺序无关、可逐字节复现。

聚合层（会话汇总、日聚合）对已落库的 micro 值求和，**不重新舍入**。

### 首次安装前历史的诚实降级

`computed_cost_status` 增一档 **`priced-at-snapshot`**：事件时间早于本机最早价目快照时使用，并记录所用 `pricing_version`。

[组件规格](../design/组件规格.md)把它标注为「计算值（价目回溯不可得）」，与正常「计算值」视觉可区分。之后若获得更早的价目历史（用户覆盖或上游补齐），这些行会被 reprice 重新计算并转为正常状态——**缺口可见、可修复，而不是伪装成精确值**。

## 为什么现在做

舍入策略是收敛契约的一部分而不是实现细节：`reprice` 会被反复执行（价目刷新、normalizer 升级、定格边界变化），如果两次执行结果不同，"终态一致"这条验收在成本列上就不成立，而成本是产品的主输出。

`priced-at-snapshot` 影响 `computed_cost_status` 的取值域，属 M0.5 冻结门内的 schema 决策。而它要标注的那批数据——首次导入的全部历史——恰恰是用户第一次打开产品时看到的东西。

## 代价与备选

- **备选一：价格列改为 `unit_price_nano_usd`。** 弃选理由：micro 域配 `per_unit = 1e6` 已能精确表达现实价目的下限（cache read 量级 $0.03/1M 即每 1e6 单位 30,000 micro，精确），改列只带来迁移成本而不解决实际问题——**问题在计算过程不在存储精度**。这一条是必要性检验筛掉的过度设计。
- **备选二：成本存 REAL，不舍入。** 弃选理由：schema 已论证过 REAL 聚合漂移不可接受，且浮点求和本身与顺序相关，反而破坏决定论。
- **备选三：按会话或按天计价一次，不逐事件计价。** 弃选理由：事件级成本是下钻的基础，且事件可能跨定价区间。
- **代价**：逐事件舍入会在极小额事件上产生最多 0.5 micro-USD 的单次误差。取 round-half-even 使其无偏，量级上不可见；用截断则会系统性低估。
- **代价**：`priced-at-snapshot` 让首次导入的历史成本带一个降级标注，产品第一印象里就有"不够精确"的信息。这是有意的——[ADR-0002](0002-数据架构.md)的溯源原则本来就要求"缺口可见而非虚报"，在这里对自己也适用。

## 后果

- `computed_cost_status` 取值域增 `priced-at-snapshot`。价格列保持 `unit_price_micro_usd`，不改。
- 计价是纯函数，property test 验三条：舍入可复现、求和顺序无关、重复 reprice 幂等。
- ADR-0002「成本所有权与可重算」节的计价规则引用本 ADR。
- [组件规格](../design/组件规格.md)溯源标注增第五档。
