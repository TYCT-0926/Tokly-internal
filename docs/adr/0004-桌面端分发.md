# ADR-0004: 桌面端分发策略

- 状态：accepted（2026-08-02 **三轮终审**：Tauri 直嵌 Rust core 定案，sidecar 路线与 M5 决策门废止。**2026-08-03 四轮**：「最低系统版本」一条被 [ADR-0009](0009-运行期基线.md) 取代；签名、公证与更新移交 [ADR-0013](0013-分发信任链.md)。直嵌决策与两 transport 结构不变）
- 日期：2026-08-02

## 背景

桌面端 = Tauri 2 壳（托盘 + 可钉 Widget + 完整窗口），窗口复用 Web Dashboard 构建产物。三轮终审把内核定为 Rust（[ADR-0001](0001-技术栈与运行时.md)），「JS 核心如何随桌面端分发」这个问题本身消失。

## 决策

**Tauri 2 直嵌 Rust core：core 以库形式静态链接进 Tauri 进程——无 Bun sidecar、无 Node、无独立进程。** 托盘 / Widget / 窗口全部读同一个进程内 application service。二轮审查的「托盘 Rust 直读 SQLite」候选方向（共享 .sql / 视图方案）被本决策吸收：不是 Rust 侧绕过 core 直读库，而是 core 本来就在进程里。

**两 transport 薄适配**：同一个 Rust application service 暴露两套边界——

1. **Tauri IPC / events** → 桌面窗口内 React（command 调用 + event 推送，浏览器侧 SSE 的等价物）；
2. **Axum HTTP + SSE**（仅 127.0.0.1 + 随机 token）→ 浏览器 Dashboard（`tokly serve`）与第三方端。

service 与 transport 无关，transport 只做序列化 / 推送适配，不含业务逻辑。桌面端同时也是 daemon 候选：写入单 owner 进程模型不变（见 [架构总览](../架构总览.md) 进程模型）。

**安装体积目标 ~10MB 级**：Tauri 2 壳实测 2.5–10MB + Rust core 静态链接个位数 MB（原 sidecar 方案 100–110MB 的约 1/10）。三平台体积 / 冷启动 / 空闲内存在 M0.5 跨端竖切 spike 实测定格（[路线图](../路线图.md) M0.5）。

**废止（2026-08-02 三轮终审）**：

- 原「v1 内嵌 Bun sidecar（~100–110MB）」方案——随 Bun 退出产品栈作废；
- 原「v2 托盘/Widget Rust 直读 SQLite」候选方向——被直嵌方案吸收；
- 原「M5 开工时最终决策门」——决策已提前做出，不再设门；
- 原「发行 JS 包、依赖用户已有 Bun/Node」路径——产品不依赖任何 JS 运行时。

**Tauri 边角坑（保留登记，补充最低系统版本）**：

- macOS 托盘常驻应用需 Accessory 激活策略（`NSApplicationActivationPolicyAccessory`），否则 Dock 图标与焦点行为错乱。
- Linux 透明窗口在部分 NVIDIA 驱动下渲染异常——**默认不透明**，透明仅作显式开启项。
- ~~最低系统版本：macOS 12+；Linux 依赖 webkit2gtk-4.1~~ —— **被 [ADR-0009](0009-运行期基线.md) 取代**（macOS 14+；Linux 按 WebKitGTK **引擎** ≥ 2.44 而非 API 版本号——`webkit2gtk-4.1` 是 API/ABI 版本，不表达渲染能力）。WebKit 系能力滞后风险见 [风险登记](../风险登记.md) R6 / R7。
- ~~sidecar 进程清理（Windows Job Object）~~——随 sidecar 路线废止，条款移除。

SQLite schema 仍为跨进程公共契约：变更需迁移脚本，禁止破坏性改写（不变）。

## 备选及弃选理由

- WebView 内跑核心（sql.js/OPFS）：性能与持久化模型不达标，弃。
- 要求用户独立安装 CLI、桌面端仅做客户端：安装路径割裂，违背开箱即用，弃（架构上不阻止：桌面端发现已有本地 daemon 时连接之，见进程模型端口文件发现）。
- sidecar（核心外置进程，任何语言）：进程生命周期 / 端口管理 / 孤儿进程全是白交的复杂度，core 已是 Rust 后零收益，弃。

## 后果

- CI 三平台产出：Tauri 安装包（单产物，内嵌 core）+ cargo-dist CLI 原生二进制（[ADR-0006](0006-开源发布.md)）；签名与公证是产出的一部分，见 [ADR-0013](0013-分发信任链.md)——未签名的安装包在 macOS 装不上，不是体验问题。
- 桌面端无 sidecar 生命周期管理职责（退出清理 / 崩溃重启 / Job Object 条款随路线废止）；写入单 owner 由进程模型约束——同一时刻只有一个进程持有写锁，桌面进程内嵌 service 即 daemon 候选之一。
