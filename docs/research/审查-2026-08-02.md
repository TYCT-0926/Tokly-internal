# 深度审查报告（2026-08-02，外部模型复审）

方法：通读仓库全部文档 + 6 路独立验证（竞品一手数据、技术选型交叉验证、盲区扫描、上游源码抽查、schema 对抗性测试、OKLCH 数值实证）+ 2 项本机只读实测（Claude 重复行 usage 一致性、Codex cache_write 分解）。以下结论全部附证据链；本机实测已复核确认（Bun 1.3.14 无 node:sqlite，实测 "No such built-in module"）。

## 一、理解确认

六源（JSONL/SQLite/API）→ 各自 adapter → 归一化 UsageEvent → 水位线增量摄取 + (source,eventId) 幂等入库 → 本地 SQLite 唯一事实源 → pricing 层可重算成本 → 三端读同一库 → design-tokens 三渲染器统一视觉。决策依赖链：只读铁律决定数据上限，能力矩阵与溯源标注是补偿；本地建仓对抗源清理；全 TS+Bun 使一核三端成立；三层令牌把设计纪律程序化。

## 三、优化清单

### P0 · 动工前必须改

1. **摄取契约：insert-once 改带 revision 的 upsert，幂等重定义为「收敛性」**。六源中四源要求覆盖语义。Claude first-wins 实测低估 3,649 万 output tokens；copilot 月度 API 事件会冻结在月初值；cursor 冻结在流式首帧。方案：`INSERT ... ON CONFLICT(source,eventId) DO UPDATE WHERE excluded.revision >= usage_events.revision`；sessions 改「受影响 sessionId 局部重算」；幂等测试改为「任意扫描切分与重放顺序 = 对源终态一次完整扫描」。
2. **token 口径两条不变量写入 ADR-0002**：`input 为净值，与 cacheRead/cacheWrite5m/cacheWrite1h 四者互斥`（codex 是含缓存毛值，不改则虚高约 12 倍）；`output 恒含 reasoning，reasoning 仅为信息性子集`（gemini/opencode 映射需改）。加跨 adapter 一致性测试。
3. **SQLite 路线改显式双驱动适配**：SqlDriver 抽象下运行时检测（Bun→bun:sqlite，Node→node:sqlite，注意 API 不同）；「core 在 Node 24+ 无损运行」升为硬约束——对冲全部 Windows 风险（收敛于 Bun 单点）。
4. **配额窗口升为一等公民**：独立 quota_snapshots 表（source, account, observedAt, limitId, usedPct, windowMinutes, resetsAt, raw）；Codex adapter 采集 rollout 里现成的 rate_limits 快照；Claude 侧本地重建 5h 窗口+燃烧率（标注推算）。路线图从"不存在"提到 M1–M2。

### P1 · 架构级

5. **UsageEvent 扩列组**（判据：不可逆性）：status('counted'|'excluded')+excludeReason；granularity+periodEnd+channel；serviceTier；agent/mode、gitBranch；durationMs；cliVersion；rawSchema 版本；model 定死 string|null 禁魔法值；project 拆 projectKey+projectLabel。
6. **copilot 四通道权威裁决**：同 source 多 channel 由用户配置唯一权威通道，非权威入库但 status='excluded'。
7. **水位线表泛化**为 (source, channel, streamKey, kind, cursor JSON, fingerprint)；修三个静默丢数据点：cursor VACUUM 后 rowid 重编（指纹改水位线 rowid→key 反查）；opencode finish 永空的中断轮次（finish 非空 OR error 非空 OR 陈旧 N 分钟即定稿）；同毫秒并发跳过（水位线回退 2s 重叠扫描，靠 upsert 吸收）。
8. **reprice 从归一化列重算**（而非 rawUsage——pricing 层不应懂六种源格式，且源文件 30 天后消失）；**成本双列** costNativeUSD + costComputedUSD（OpenCode 低估 bug 变差异化提示）。
9. **tool_calls 独立表**（含 status/时长）+ **event_charges 子表**（premium-request 数可索引聚合）；废弃"零 token 独立事件"。
10. **主题派生引擎 gamut-aware**：fg.muted L0.58→0.62（原值全部种子过不了自定的 4.5 门）；accent.solid 加自动修正/校验门；种子校验 accent L∈[0.45,0.85]；heat ramp 统一缩放（先算各档可显示 C 上限取 min 比例，而非逐点 clamp）；质量门加 accent.solid 对比与 C 单调性两项。
11. **三端进程模型**：单 daemon 所有权（端口文件发现，TUI 降级只读直连）；watcher/轮询节奏写入架构；schema_version 协商（版本漂移拒开）。
12. **桌面 Rust 直读上调**：托盘/Widget Rust 直读 SQLite 作为 v1 候选方向（M5 开工时最终决策）；聚合查询下沉为共享 .sql/视图；Tauri 边角坑（macOS Accessory 策略、Linux 透明+NVIDIA 默认不透明、sidecar 进程清理 Windows Job Object）。

### P2 · 产品与增长

13. **计价表达力**：价格键扩为「模型 + service_tier/speed + 上下文档位」；价目表加生效日期维度（自建覆盖层）；credits 显式声明为"额度"不硬折美元。
14. **adapter 广度**：优先 Cline/Roo/Kilo 家族（一套 globalStorage 解析覆盖约 900 万安装）与 Qwen Code（复用 Gemini adapter ~80%）；包装「adapter 贡献套件」（spec 模板+快照测试脚手架+能力声明 checklist）。
15. **增长三件套**：README 英文化（ADR-0007 开例外）；`tokly report` 终端汇总进 M1（里程碑可 dogfood 才成立）；`tokly serve --demo` 假数据模式。
16. **路线图重排**：M1=core+claude+pricing+report；M2=Dashboard v1（Claude+OpenCode 两源，防 UI 过拟合单源）；M3=广度（codex/gemini+配额完整化）；design-tokens+preview 单列里程碑。
17. **TUI 走 @opentui/solid 路径**；Windows 降级预案（降帧/禁特效）或引导走 Web，诚实标注。

## 四、盲区报告

1. **订阅配额窗口（最重）**：目标用户主体是订阅用户，"5h 窗口还剩多少"是每天撞墙的真问题；官方 /usage 已杀死单工具监控生态位，但没人做跨工具聚合；Codex rollout 里就躺着官方 rate_limits 快照。
2. **codeburn 与 token-monitor**：竞品调研成文即过时；codeburn 差 Tokly 只差持久化仓库层，窗口期按月计算。
3. **价格的时间维度**：用今天的表回算历史是 bug 温床；需带生效日期的价目历史。
4. **多通道同源双计**：OTEL+文件+API 三通道并存的权威裁决。
5. **Windows 风险收敛于 Bun 单点**：OpenTUI bug、node:sqlite 缺失、94MB 地板、sidecar 孤儿进程同源于 Bun，需独立风险条目。
6. **失败的可见性**：解析坏行/跳过行无记录（需 ingest_errors 表或 scan 报告）；30 天删源下静默丢弃=永久丢弃。
7. **存储预算乐观 5–10 倍**：500B/条不含索引与页开销，三年重度使用是 GB 级；缓解：计价字段升一等列后 rawUsage 仅在有损时存。
8. **本地服务无鉴权**：127.0.0.1 任意进程可读全部用量+项目路径，加随机 token。
9. **opencode 活库 immutable=1 可能读到撕裂页**：改 mode=ro + busy_timeout。

## 五、一个诚实的回答

推翻「美元成本是唯一一等指标、配额窗口不进数据模型」这个隐性决策。目标用户主体用订阅制，每天真实遭遇的是撞窗口上限而非看等效美元；这个赛道活得最好的功能全是油表不是账本；配额+永久历史+跨工具聚合的组合才是还没被占住的真空位。第二名是 Bun-first 赌注，但它只需 50 行适配层 + Node 逃生通道，产品方向的错误没有这种便宜的补丁。
