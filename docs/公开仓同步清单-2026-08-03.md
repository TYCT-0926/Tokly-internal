# 公开仓待应用变更清单（2026-08-03）

**临时工作文档**：公开仓工作树恢复后逐条应用，应用完即删（git 记得它）。依据 [审查-2026-08-03](research/审查-2026-08-03.md)，编号对应该报告的问题号。

**边界提醒**：应用时不得把内部文档路径写进公开仓。凡需引用内部决策，一律写「内部 ADR-NNNN」文字提及，不给链接（公开仓 `docs/开发流程.md` 已有此惯例）。

## 0. 最优先：泄漏与误删防线 + AI 痕迹清除（#82 / R12 / 仓库策略「可见性与痕迹控制」）

在**恢复公开仓工作树的同一次操作里**完成，早于任何内容改动：

1. 外层 `.gitignore` 增 `/internal/`；
2. `.git/info/exclude` 写入 `/internal/`、`/CLAUDE.md`、`/AGENTS.md`（本地排除，不随仓库分发）；
3. **移除已提交的 AI 协作文件**：`git rm --cached AGENTS.md CLAUDE.md`——文件留在磁盘供本地 AI 协作者读取，仓库不再跟踪；其贡献者适用内容并入 `CONTRIBUTING.md`（无 AI 字样）；
4. `.githooks/pre-commit`：拒绝 `internal/` 路径与 `AGENTS.md`/`CLAUDE.md` 的暂存，并 `git config core.hooksPath .githooks`；
5. 公开 CI 增路径前缀检查（`internal/`，防 `--no-verify` 绕过）。**私有文件名单 grep 移到本地 pre-push hook，不进公开 CI**——名单写进公开配置等于把内部文档的存在与命名公示；
6. 团队约定：**禁用 `git clean -xdff`**，清理走 `cargo clean` 或 `git clean -xdf -e internal`；
7. **M1 发布前历史重置**（仓库策略历史层防线）：当前公开仓初始提交含 AGENTS/CLAUDE，趁零 fork 窗口期以全新 orphan 历史重建 main（或新建仓库替换），使第一个公开可见 commit 干净。此步可与 M1 首发并批执行，但决定现在记下。

## 1. `docs/设计原则.md`（#50 / #58）

这份文件是公开仓唯一的 UI 施工依据，却停在三轮换栈之前。六处改 + 一处结构调整：

| 位置 | 现状 | 改为 |
|---|---|---|
| 信息架构 §2 | 「趋势图（uPlot）」 | 「趋势图（ECharts 6 模块化懒加载）」——uPlot 已被内部 ADR-0001 推翻 |
| 主题系统段 | 首发主题列四套 `amber / mono / slate / paper` | 补 `sakura`（表现力证明），共五套 |
| 色彩段 | 「签名主题为暖近黑（`#0E0C0A` 附近）」 | 删除具体 hex，改为「签名主题为暖近黑，具体值由令牌派生产出」——该孤值与种子 `#171310`、派生输出 `#120F0C` 三者互不相同 |
| 形状与间距段 | 「卡片 8–10px」 | 「卡片 10px」，与令牌一致 |
| 动效段 | 「列表首次入场 stagger 30–80ms」 | 「热力图按周列 stagger 每列 8ms，总量封顶 500ms」，与内部动效规格一致 |
| 个性预算段 | 「只允许一个签名时刻」 | 保留"一个"，并明确该签名时刻是**热力图首次入场**；下钻过渡与 Widget 呼吸改称"功能性动效"，不占个性预算（原文 1 对 3 的矛盾由此消解） |
| 信息架构 | 第一屏 =「现在花了多少（KPI）」 | **第一屏 = 配额油表（有配额源时）→ KPI → 趋势与热力图 → 下钻**；无配额源时第一带直接是 KPI。理由：内部 ADR-0008 论证油表是差异化第一位，而原信息架构把它排除在外 |

另增两段（可直接引用内部规格的公开版本表述）：

- **溯源标注五档**：官方 / 工具自算 / 计算值 / 计算值（价目回溯不可得）/ 估算；
- **保留边界的诚实呈现**：事件明细按保留窗口滚动，会话汇总与日聚合永久——超窗下钻处必须说明而非显示空表。

## 2. `docs/开发流程.md`（#65–#70 / #48）

**CI 章节**增四项门禁：

| 门禁 | 内容 |
|---|---|
| DDL 一致性 | 从内部 schema 文档提取的 SQL 与迁移代码建库后做 `sqlite_schema` diff（公开仓侧只描述机制，SQL 源文件随实现进仓） |
| 样式与动效纪律 | Stylelint 自定义规则：只允许 `transform`/`opacity` 过渡、时长只允许令牌变量、禁 `transition: all`；禁止清单静态项（非白名单 `linear-gradient`、`backdrop-filter`、emoji 码点、`border-radius > 12px`、`box-shadow` blur > 24px） |
| 帧预算 | Playwright trace 采集三场景 frame timing，断言「不允许连续 >2 帧超 16.7ms」；主题切换逐帧截图断言图表与页面同帧 |
| 依赖与许可 | `cargo-deny`（advisories + licenses + bans）、`cargo-audit`、`pnpm audit`；许可证兼容从断言变成门禁 |

**测试策略表**增两行：跨语言格式测试向量（Rust 与 TS 同一份 fixture 必须同时通过）；性能基准明确基准数据集为 `bench-3y`（三年跨度、六源、120 万事件，由 `cargo xtask bench-fixture` 确定性生成）——**没有定义数据集规模的延迟指标不可验收**。

**Definition of Done** 增两条：涉及跨仓概念的改动按跨仓事实映射表核对镜像方；新增/变更配置项须同步配置面文档。

## 8. `SECURITY.md`（ADR-0012 / ADR-0014）

- **显式写入"不做遥测"**：无使用统计、无崩溃上报；出站网络只有定价表刷新（可关闭）与用户显式授权的 API 源；
- 本地服务的威胁模型与防线：仅 `127.0.0.1` + 随机 token（POSIX `0600` / Windows DACL）+ `Origin`/`Host` 校验拒绝 DNS rebinding + token 经 URL fragment 不进访问日志；
- 凭据只存系统钥匙串，并说明无 secret service 的 Linux 环境下的行为。
